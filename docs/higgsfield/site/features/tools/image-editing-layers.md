# Higgsfield Layers (Image Studio) - layer separation and edits

Source: https://higgsfield.ai/higgsfield-layers ("Powered by Seedream 5.0")

- **Layer separation**: split a flat image into editable layers (subject, background, details) - then move, retype, relight, upscale.
- **Edit text** in the image, **regional edit**, **Draw to Edit** (sketch on the frame to remove/add/replace), **Remove Background** (alpha cut-outs with hair detail), **Upscale** (up to 4K with detail recovery), **Relight** (move key light, warm it, add drama - match stock/AI images to your scene), **Skin enhancer**.
- Flow: upload -> describe edit in natural language or draw on frame -> generate/export.
- Pricing note (AI Photo Editor FAQ): layer separation and region edits are paid-plan features that use credits.
