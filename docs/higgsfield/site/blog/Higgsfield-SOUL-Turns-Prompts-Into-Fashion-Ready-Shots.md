Launch post for **SOUL**, Higgsfield's own photoreal fashion image model.
- 50+ curated style presets (e.g. iPhone flash, Dune-core, masked looks, giant hands). Pick a preset + type a simple idea — no prompt engineering needed.
- Each run returns 4 distinct images; outputs deliberately include camera imperfections (dust, flash, grain) for authenticity.
- Free on all plans (at launch).
- Intended pipeline: SOUL still -> animate with Camera Motion -> VFX -> Speak (voice) -> Canvas edits -> voiced ad.
- Audiences: photographers sketching references, stylists/lookbooks, UGC ad makers, TikTok-native visuals, concept artists.
