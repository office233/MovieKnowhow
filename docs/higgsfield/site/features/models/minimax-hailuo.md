## MiniMax H3 (Hailuo 3)
- Successor to Hailuo 2.3; open-weights general multimodal video model; runs on Higgsfield infra.
- Output **2K** (1440 px short edge), 24 fps, **5-15 s selectable per second** (Hailuo 2.3 was 10 s max).
- Aspect: 21:9, 16:9, 4:3, 1:1, 3:4, 9:16 + adaptive; with first/last frame input the output follows the input image ratio.
- References: up to 9 images + 3 clips + 3 audio tracks, **12 files max**; audio must be paired with >=1 image or video. Prompt up to **7,000 characters**.
- Stereo audio on every generation (score, dialogue, foley, ambience); can transfer/clone a voice from a reference recording onto a character.
- **Instruction-based editing** of existing footage: swap product/character, replace background, relight day->night, remove object, rewrite a dialogue line - untouched areas stay stable.
- Legible text/UI: packaging labels, subtitles, credits, HUDs, product pages, motion posters.
- Prompting tip from the page: **cite each reference by name and describe the shot like a director**.
- vs Kling 3.0: Kling goes to 4K and is built around multi-shot storyboarding; H3 caps at 2K but takes richer input and edits footage.
- API list price $0.13/s (launch $0.091/s). Hailuo 2.3: $0.0467/s (75% off: $0.0117/s) - cheapest video on the API list.
- Site-wide: "Minimax for fast, high-fidelity motion from minimal prompts, quick UGC-style clips and rapid iteration"; "Hailuo 2.3 for fastest and stylized output".
