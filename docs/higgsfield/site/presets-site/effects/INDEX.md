# Higgsfield site — Effects presets (higgsfield.ai/effects)

All 87 effect example pages plus the /effects listing, extracted from the page data embedded in each crawled page. Every preset here is a **chain** preset (`job_set_type: viral_hub_video`) with the **same id as the Viral Hub (MCP) entry** in `../../../presets/viral/`. That means each file below gives the input schema, settings, prices and preview URLs that the viral notes were missing.

Key facts:

- **No example prompts are published.** Every public sample was made with an empty prompt. 21 presets have an optional free-text `Prompt` input (see PROMPTS.md); the rest take only media.
- **The model is never named.** Sample jobs report `model: null`. The one hint is a slug suffix (`casual-monster-slayer-seedance-2` suggests Seedance 2).
- **Two families.** 54 image-to-video effects have a fixed clip length (5-15 s), a resolution + aspect-ratio picker and matrix pricing. 33 are **Mixed Media** video-to-video restyles (tag `Mixed Media`), priced per frame. The Mixed Media ones are also in `../mixed-media/`.
