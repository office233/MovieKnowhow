## Notes

**Topic:** Higgsfield plugin for Figma/FigJam — keeping brand visuals consistent (Jul 23 2026). No prompts.
- Tools: Generate AI Image (runs on **Soul 2.0** for consistent on-brand identity), Generate AI Video (looping backgrounds, hero animations), Remove Background, **Relight** (push a stock photo to the file's light direction/warmth), **Color Grading** (lock one mood across mixed-source images), **Expand** (full-bleed/other aspect ratios without reshoot), **Angles** (front, side, 3/4 views from one product photo for catalogues).
- Install from Figma Community (search "Higgsfield"), sign in; results land on the selected frame as normal layers (auto-layout/constraints apply).
- Workflow: generate hero background with setting + lighting + colour register described -> Relight clashing stock photos until they match -> Expand to each placement's aspect ratio -> Remove Background on client photos -> Angles + one Color Grading across a catalogue set.
- Tips: be specific about subject/style/mood; start refinement tools from sharp, well-lit sources; select the target frame before generating. Same credits as web; commercial use on paid plans.
