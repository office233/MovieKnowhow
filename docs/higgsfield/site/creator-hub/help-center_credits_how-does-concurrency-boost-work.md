# How does Concurrency Boost work?

Source: https://higgsfield.ai/creator-hub/help-center/credits/how-does-concurrency-boost-work
Published: Aug 3, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (credits). Concurrency Boost = one-time pack adding +4/+8/+12/+16 parallel generations (max +16) plus Boost Credits (shared across all models and Supercomputer, valid 90 days). Per-pack toggle: on = boosted concurrency drawing Boost Credits; off = normal credits and base limit. Highest-concurrency pack drains first; equal-level packs pool. Buy via Boost speed / Increase Concurrent / Manage Account -> Usage. Useful for large batch sprints.
