Higgsfield's "production stack" of five features on top of 15+ models (Seedance 2.0, Veo 3.1, Kling 3.0, WAN 2.6…):
1. **Soul ID** — trained identity (not a reference matcher): higgsfield.ai/character, upload **20+ photos** with varied angles, lighting, expressions. Works across Seedance 2.0, Kling 3.0, Veo 3.1 and Nano Banana Pro; reuse indefinitely. Reference matching weakens when the scene/angle/lighting differ; trained identity holds.
2. **Cinema Studio** — camera move specified is executed at generation time across models; reuse the same camera language across clips for sequence consistency. Terms that execute directly: *dolly in, dolly out, truck left, truck right, arc shot, push in, pull back wide, handheld follow, crane up, orbital move, tilt up, tilt down*.
3. **Marketing Studio** — paste product URL -> extracts name, images, features, price -> script -> video on **Seedance 2.0** with native audio (VO + lip sync in the same pass); optional Soul ID spokesperson; pick output format (vertical/horizontal/square). Steps: higgsfield.ai/marketing-studio -> URL -> edit script -> attach Soul ID -> format & resolution -> Generate -> download.
4. **LipSync Studio** — native lip-synced speech (Kling 3.0 Lipsync, Veo 3.1…), 8+ languages; switch language without re-rendering visuals; same Soul ID face across language versions.
5. **Supercomputer** — high-throughput parallel generation, Ultra plan ($129/mo, 3,000 credits, up to **8 videos + 8 images in parallel**).
Workflow chain: Soul ID defines character -> Cinema Studio camera -> Marketing Studio ad -> LipSync localization -> Supercomputer volume.
