# Higgsfield Collab (shared projects, chat, calls, community)

Sources:
- https://higgsfield.ai/chat-intro

Source page title: "Higgsfield Collab - Shared Projects, Collab, Calls & Community". Monetisation side (karma, earn) is in [../../blog/Higgsfield-Earn-Talent-And-Collaboration-Monetization.md](../../blog/Higgsfield-Earn-Talent-And-Collaboration-Monetization.md).

- **Projects** are shared spaces (DMs and group chats are projects too) where members generate together, chat, share assets and start **audio/video calls** (any project with 2+ members; persistent call bar while you navigate).
- **Share to Collab** toggle sends a generation into the project chat with its **model, prompt and progress visible**, so teammates can react, remix or approve. Useful for directors reviewing shots.
- Project visibility: private (invite only), public (discoverable, view-only), open (anyone can join); public/open have Request-to-Join with owner approval. Fine-grained access control per user.
- **Organisations**: free Org = shared name, each member uses own credits; paid Org (Team plan) = shared credits, shared elements, admin controls, SSO; every Team workspace is an Org.
- **Karma**: earned by liking, commenting, generating and inviting; exchangeable for credits. Community feed shows trending published work; publishing builds karma and discoverability.
- Suggested uses: agencies (client review/approval in context), AI filmmakers (storyboard together, feedback on edits via chat, calls to align), educators (students as project members, critique).
