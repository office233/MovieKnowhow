# Higgsfield plugin for Figma

Source: https://higgsfield.ai/plugins/figma

## Notes

- Install from Figma Community (search "Higgsfield") or right-click canvas -> Plugins. Works in Figma design files **and FigJam**, desktop and browser; no installer. Sign in once to connect credits.
- Tools (one panel): Generate image, Generate video, and five image apps that act on the selected image: **Remove Background, Color Grading** (warm, teal-and-orange, muted film, high-contrast profiles to lock a mood across a frame set), **Relight** (move/warm the key light after the fact), **Expand** (outpaint to a new aspect ratio) and **Angles** (front/side/three-quarter views of the same subject).
- Output lands on the selected frame as normal image/video layers.
- Tip from the FAQ: be specific about subject, style and mood; select the target frame first; start Relight/Color/Expand from a clean source image.
