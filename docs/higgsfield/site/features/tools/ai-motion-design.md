# AI Motion Design (code-to-video engine)

Source: https://higgsfield.ai/ai-motion-design

- Generates motion graphics as **code** (so every element is a tunable variable): data-driven infographics, kinetic typography, logo reveals, presentations, kinetic captions.
- 5-step flow: prompt your idea in chat -> optionally upload logos/SVGs/images/footage -> apply Motion Presets (pre-built easing/animation) -> refine in a visual inspector (edit the code, not pixels) -> render up to 4K.
- Inspector controls: exact HEX/RGB colours, drag-and-drop text position with social-safe zones, duration/delay/easing sliders, fonts/tracking/leading.
- Related: Vibe Motion workflow; Supercomputer "Motion Designer" employee (43 skills).
