# Higgsfield Genjutsu (reality manipulation for video)

Source: https://higgsfield.ai/genjutsu

- Two modes on an existing video:
  - **Motion Transfer** - keep motion, camera and timing; rebuild everything else (cast, location, look) from references.
  - **Object Swap** - change a selected character, outfit, product, text, location or object; the rest of the shot stays untouched.
- Reference video 4-30 s; up to **30 reference images** (characters, products, wardrobe, props, locations).
- **Batch**: run many versions from one setup, then generate more of what works.
- Use: shoot on your phone once, let Genjutsu do wardrobe/set/grade; A/B product swaps; same take in two realities.
- Credits shown before generating. API: $0.318/s (launch 50% off: $0.159/s).
