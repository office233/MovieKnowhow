## Notes

**Topic:** starting a faceless channel with AI — tools, workflow, automation (Aug 3 2026). No prompts.
- Formats: explainers, documentary-style, narrative retellings (horror, mythology, true crime), list/"versus" formats, mascot/character-driven. Common thread = **repeatability** (next episode recognisably the same channel).
- Stage -> tool: niche & concept (Supercomputer) · script (Supercomputer / Claude) · video (Cinema Studio for narrative/cinematic identity; Seedance 2.0 / Kling 3.0 for fast clear visuals) · voice (Seed Audio 1.0 with ambience; **VibeVoice for multi-minute narration**; Seed Speech for 30+ languages; 50+ presets or custom voice) · consistency (Soul ID for a recurring mascot/character from 20+ refs; Popcorn to storyboard multi-shot episodes, 4 refs, 4/6/8 frames) · publishing (Supercomputer **Scheduled Tasks** to YouTube, Shorts, TikTok).
- Workflow: narrow repeatable niche -> consistent script format (same intro, pacing, sign-off) -> video (train Soul ID before episode 1; Popcorn for multi-shot) -> voice matched to length/markets -> review the whole episode (voice tone vs visual tone, rhythm) -> schedule.
- Vertical cuts are **separate assets** (different pacing, framing, and a new hook in the first 3 s) — build them into the pipeline from day one, not as crops.
- Tips: lock the niche first; test voice+video pairing on one full episode before batching; spot-check automated runs periodically.
