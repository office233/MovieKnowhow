## Notes

**Topic:** credits vs unlimited pricing across AI video platforms (prices verified Sep 11 2026). No prompts.

**Credit mechanics:** cost depends on model tier, duration and resolution (1080p often 3-4x the 720p rate), audio surcharge on some models, and **retries (failed takes cost the same)**. Subscription credits usually expire each cycle; top-ups have their own expiry. Real unit of cost = one usable clip, which takes **3-5 generations** in their tests.

**Compare cost in 5 steps:** usable clips needed -> x retry rate (3-5) -> price those generations at your model's rate -> compare with a flat plan/pass for that model -> check scope (surface, resolution, concurrency).
Example on Higgsfield: **Seedance 2.5, 8 s 1080p = 72 credits (~$3.60)** per take. Light (10 clips, 30-50 gens) $108-180 -> plan credits fine; Regular (30 clips, 90-150 gens) $324-540 -> a 3- or 7-day pass is cheaper; Heavy (100+ clips) $1,080-1,800 -> passes/windows for iterations, credits for finals.

**Higgsfield plans (Sep 2026):** Starter $15/mo = 200 credits, no unlimited set. Plus $49/mo ($39 annual) = 1,000 credits + 365-day unlimited set of six image models + 7-day Nano Banana 2 window. Ultra $129/mo ($99 annual) = 3,000 credits + same set + windows on Nano Banana Pro and Nano Banana 2. Annual adds a Kling 3.0 window; free Soul V2 / Soul Cinema generation pools 3,000-10,000 by plan. Kling 3.0 8 s 1080p showed 20 credits (~$1). Unlimited Models Marketplace: 1/3/7-day passes per model, $7 (1 day) up to $1,035 (7-day all models).
**Caveats:** unlimited applies only on higgsfield.ai web — **MCP, CLI, Canvas, Supercomputer use credits**; standard queue; per-model resolution/duration caps; new flagships arrive as windows/passes.

**Competitors (snapshot):** Midjourney Relax (unlimited images from $30 Standard, SD video on Pro/Mega, 3 concurrent); Kling credits only ($10-$180, rates shown at generation); Runway closed Unlimited to new subs Jun 1 2026 (Gen-4.5 = 12 cr/s, 5 s = 60 cr); Luma per-second credits (Ray 3.2 5 s 1080p = 400 cr; Seedance 2.5 1080p with audio = 319 cr/s); Adobe Firefly first-year unlimited on partner models; Magnific model-capped set; Hailuo unlimited older models on Max ($184), MiniMax H3 from $0.027/s; Vidu off-peak unlimited on Max.

**Decision guide:** occasional -> base credits; heavy on one model -> unlimited/pass on that model; testing many models -> hybrid plan; multi-stage professional -> multi-model subscription; API/pipeline -> credits (unlimited never covers API).
