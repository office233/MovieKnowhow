## What it does

Apply professional cinematic color grades to your photos. Adjust temperature, hue, saturation, contrast, and more with real-time WebGL preview.

**Free, credit-less standalone grader.** Upload PNG/JPG/WebP and adjust temperature, contrast, saturation, highlights, exposure, sharpness and film grain from one panel, with a real-time WebGL preview. Start from a preset look, then fine-tune. Preset looks shown in the demo: **Natural, Split Tone, Soft Skin, Old Lens, 16mm**. The same controls are built into **Cinema Studio 2.5**.

**Technique:** grade the key frame *before* animating it. A graded still used as the start frame for image-to-video carries a consistent look into the clip, so the whole film shares one grade. The page calls grading the "finishing layer" for raw AI frames.
