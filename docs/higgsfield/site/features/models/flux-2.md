# Black Forest Labs FLUX.2

Source: https://higgsfield.ai/flux-2-intro

- High-fidelity image model with stronger physics (light, gravity, object interaction) and world knowledge (real locations without hallucination).
- **JSON / structured prompting**: specify camera angle, lens, shot type, style, mood as fields.
- **HEX colour control**: put exact HEX codes in the prompt for object colours and gradients (brand consistency).
- Native multi-language prompting (e.g. Korean, Thai, French) and infographics.
- Variants: FLUX.2 Pro, FLUX.2 Max ("sharp text, maximum detail"), Flux 2.0 editing. Flux 3.0 Video Upscale (up to 4K) is a separate tool.
