## Notes

**Core idea:** the prompt carries *what happens*; the director's panel carries the *visual logic* (applied at generation time, not as filters). Every setting you leave on Auto is a decision the model makes for you, usually a bland middle ground.

**Settings reference (3.5):**
| Setting | Options |
|---|---|
| Genre | General, Action, Epic, Drama, Comedy, Horror, Noir |
| Color Palette | Auto, Naturalistic Clean, Bleached Warm, Hyper Neon, Teal & Orange Epic, Sodium Decay, Cold Steel, Bleach Bypass, Classic B&W |
| Camera MoveSet Style | Auto, Classic Static (Hitchcock), Silent Machine (Fincher), One Take (Lubezki), Epic Scale (Hoytema/IMAX), Intimate Observer (Sean Baker), Impossible Camera, Documentary Snap (snap zoom/whip pan), Raw Chaos (Greengrass), Dreamy Flow (Christopher Doyle) |
| Lighting | Auto, Soft Cross, Overhead Fall, Contre-jour, Window, Practicals, Silhouette |
| Camera | Raw 16mm, Fine Film (35mm), Clean Digital |
| Lens | Auto, Clinical Sharp, Extreme Macro, Anamorphic, Warm Halation, Vintage Haze |
| Focal length | 8, 14, 35, 50, 75 mm |
| Aperture | f/1.4 Wide Open, f/4 Moderate, f/11 Deep Focus |

**Lighting is causal, not cosmetic — match preset to scene:**
- Sunset walk / lavender field -> **Contre-jour** (backlight halo, face still readable). Overhead Fall there kills warmth and shadows the eyes.
- Interrogation / tension -> **Soft Cross** (90-degree side source, half face in shadow). Window would make it a calm domestic moment.
- Figure against skyline -> **Silhouette** (other presets fill the face in).
- Candle-lit -> **Practicals** (only in-frame sources, no hidden fill; Soft Cross would add an off-camera source and ruin it).
- Architectural daylight interiors -> **Window**. Temples/high ceilings -> **Overhead Fall**.

**Palette cheat-sheet:** Bleached Warm = nostalgia/golden hour; Hyper Neon = club/cyberpunk; Teal & Orange = blockbuster; Sodium Decay = thriller/anxiety; Cold Steel = military/noir/sci-fi; Bleach Bypass = war/gritty action; Classic B&W = pure mono.
**Focal lengths:** 8mm extreme wide/distorted, 14mm wide action/landscape, 35mm natural, 50mm portrait-natural (most versatile), 75mm compression and separation for intimate close-ups. **Aperture:** f/1.4 isolation/low light, f/4 default working aperture, f/11 landscape/environment.

**New in 3.5:** **Claude Chat** = built-in AI director: sets Genre/Style/Camera via conversation (panels update live), sees all Elements and writes prompts with real @tags, splits scripts into shots with camera params prefilled; it only fills the prompt box — *you* press Generate. **Elements** replaces image mode: characters/locations/props built in a dedicated flow, project-scoped but importable from other projects.

**Three worked recipes (prompts below):**
1. War beach landing, 15 s: Action, Bleach Bypass, Raw Chaos, Practicals, Fine Film, Clinical Sharp, 14mm, f/4.
2. Rally chase (6 shots): Action, Cold Steel, Raw Chaos, Practicals, Fine Film, Anamorphic, 14mm, f/4.
3. Dark-fantasy paladin vs titan, 15 s: Epic, Teal & Orange Epic, Epic Scale, Contre-jour, Fine Film, Anamorphic, 35mm, f/4.
