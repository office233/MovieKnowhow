# Common AI Video Prompt Mistakes (And the Fixes That Actually Work)

Source: https://higgsfield.ai/blog/ai-video-prompt-mistakes  
Higgsfield, Aug 3, 2026  
Prompts extracted: 14

Everything left out of a prompt still gets decided — by the model, differently every run. References fix appearance but not motion, light timing or camera end points; dense paragraphs split attention (hands/expressions degrade first); every extra person/beat multiplies interpretations.
**Seven mistakes -> fixes**:
1. Plastic/fake characters -> exact age, build, clothing + one distinguishing detail, backed by a reference or Soul ID; add small unconscious behaviors (head turn, pause, sigh). Never "add more people if it looks better".
2. Extra fingers/two suns/slop -> name every object's position and **every point of contact finger by finger**; one named light source.
3. Emotion doesn't read -> tie emotion to a visible action (held breath, gaze lifting past camera, mouth that doesn't quite smile); camera behavior carries mood too.
4. Lighting misses mood -> name source, angle, time of day (or set genre + lighting in Cinema Studio).
5. Warped movement -> describe the path (start point, end point, sharpness of turn); rigid objects stated rigid.
6. Cluttered camera / lost focal point -> **give every shot one job**; cut shots that don't serve it; end on the product in ads.
7. Characters lose positions in complex scenes -> write each person's position and background action per shot, or **storyboard in Popcorn first**.
**Six-step prompt build**: (1) scene + locked cast (setting, duration, real-time vs stylized; identities stay identical); (2) blocking before action (positions relative to camera, consistent screen direction); (3) camera as physical setup (FOV, distance, static/handheld/moving, named move); (4) action as a shot list — one beat each, start and end positions, contact points; (5) physics and lighting as real events; (6) audio (who says what, music or not) + finish (film stock, grain, grade, exclusions).
Cinema Studio settings: 7 genres, 7 lighting presets, 10 Camera MoveSet Styles, 6 lenses, 5 focal lengths, 3 apertures. Popcorn: up to 8 frames, Manual/Auto, up to 4 refs; frames are the plan, a model animates them chaining last frame into next.
Diagnosis: a prompt problem changes every run; a settings problem is wrong the same way every time.
Each section has a BAD and a GOOD prompt — the good versions are excellent templates.
