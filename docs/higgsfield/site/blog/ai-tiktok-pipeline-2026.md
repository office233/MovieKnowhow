Five stages: ideation -> script (15–60 s; hook in first 2 s, one point, payoff/CTA) -> visuals -> captions/audio -> 9:16 formatting & posting.
1. **Weekly calendar in one Supercomputer prompt**: niche, frequency, formats (talking head, product showcase, trend, educational), themes -> agent assigns formats per day + hooks (~5 min). Shows credit cost before generating.
2. **Character once**: Soul ID (20+ photos) for a real person; for invented characters, **Cinema Studio "Cast"** generates a character sheet (front, side, back views).
3. **Model per clip type** (≈ per 10 s): talking head -> **Kling 3.0 ~$1.25** (realistic skin, body motion, native lip sync); product/lifestyle -> **Seedance 2.0 ~$4** (up to 9 refs: character, product, location, style, audio); fast draft to validate hook/pacing -> **Hailuo 2.3 ~$0.60** 1080p; cinematic product reveal -> **WAN 2.6 ~$2** 1080p (dolly, orbit, DoF shifts). Generations max ~10 s here -> a 30 s TikTok = 3 clips: hook shot, demo/story beat, CTA close; plan the shot list in Supercomputer so clips form one sequence.
4. Audio/captions: LipSync Studio (8+ languages); include an audio reference for music; for burned-in captions put caption text + placement in the generation prompt (sound-off viewers).
5. **Shorts Studio** 40+ presets (Bold Urban, Green Contrast, Warm Glow…), 9:16, 33 credits (~$1.65) per 8 s 720p, input ≤ 2 min. Post with 3–5 hashtags (no direct TikTok upload from Higgsfield).
6. Batch by day or by format in parallel Supercomputer chats; **CronJobs** (Plus+) schedule recurring production.
Plan math: 20 credits = $1; Basic $9/120 cr ≈ 10 Hailuo drafts or 4–5 Kling clips; Plus $49/1,000 cr.
