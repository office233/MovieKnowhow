## AI Influencer Studio
- 3 steps: design a consistent character with image models (species toggles like Human, Elf, Amphibian, Beetle - "video-game character creator" UI) -> animate with video models -> generate ready-to-post clips for TikTok/Reels/Shorts.
- Detail tuning by prompt: add a tear, scar, makeup, imperfections, health states, posture, outfits.
- **Motion transfer**: upload a trending dance/challenge video and the character performs the same moves.
- **Brand collabs**: insert products/props into the character's hands with matched lighting.
- Companion apps: Style Snap (outfit swap keeping pose/background), Plushies (plush-toy animation), Angles (rotate/tilt the view), Recast (character swap in video), Transitions (join two clips/images with an effect).
