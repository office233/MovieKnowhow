# How do I create and use a Soul ID character?

Source: https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-create-and-use-a-soul-id-character
Published: Aug 1, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (model guide). Soul ID = trained identity layer for Higgsfield's Soul image models.

**Train**: higgsfield.ai -> Soul -> Train new character. Upload 20+ photos of ONE person (max 80), training takes a few minutes, name it, then select it in the Character tab when generating. Only use your own likeness or someone who consented.

**Photo set rules**
| Do | Avoid |
|---|---|
| varied angles and expressions | same pose repeated |
| clear, well-lit face | heavy shadows / harsh light |
| recent photos (last 4-5 months) | outdated appearance |
| at least one full-body shot | head shots only |
| unobstructed face | sunglasses, hats, scarves |
| single subject | group photos |
A smaller clean, varied set beats a large inconsistent one.

**Using it elsewhere**: works across all Soul models (Soul, Soul 2.0, Soul Cinema). For video, trained Soul characters appear automatically as Elements; in Seedance click `@ Elements` (or type `@`) and pick from My Elements. Manual path: generate an image of the character -> Assets -> three-dot menu -> Create Element.

**Limits**: expect "clearly the same person", not pixel-identical; extreme styles/angles cause slight drift. One person per Soul ID; for 2+ consistent characters use Elements. Not exportable as a file. For an invented character: generate a portrait set first (e.g. with AI Influencer), then train on it.

**Best for**: AI influencers/UGC personas, fashion lookbooks and campaigns (with Marketing Studio), personal branding. Fix inconsistency by retraining on a stronger set (replace repeated poses and shadowed shots, add full-body, keep one consistent look).
