# Recraft V4 Styles (V4.1)

Source: https://higgsfield.ai/recraft-v4-styles

- Style-locking image model: upload **1-10 reference images** (brand book, old campaigns, other generators' output); the style is captured in seconds, no training.
- Two modes per generation: **Precise** (follow the reference meticulously) or **Flexible** (keep only the mood).
- Widget defaults seen: `Recraft V4.1 Styles | Precise | 1K | 1:1 | 1/4` (batch of up to 4).
- Batch consistency claimed from frame 1 to 50; also holds characters/IP (comics, stickers, UGC series).
- Prompting advice: describe subject and composition; let the style handle the rendering - don't describe how to render.
- Save a style and reuse it; ideal for brand assets and series. Recraft 4.1 (vectors, palettes) is on the API at $0.035/image. Site: "Recraft for clean line art and coloring pages / vectors".
