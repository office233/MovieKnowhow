## Notes

**Topic:** one-account pipeline: image -> voice -> video -> edit (Sep 1 2026). No prompts.

**Why:** every export between separate tools costs consistency (voice stops matching, grade shifts, references read differently).
**Tool map:** image = Recraft (design) or Soul (character consistency); voice = Seed Audio (dialogue, narration, music); video = Cinema Studio (camera control) or Seedance (also Gemini Omni Flash); edit = Genjutsu (change one detail, 30+ presets).

**Workflow:** pick tools -> reference image -> **audio first** (VO length dictates how long shots must hold; building video around an existing track keeps sync) -> prompt video with audio + reference (e.g., Seedance 2.5) -> fix details in Genjutsu -> review/export. Timeline editing/compositing may still go to DaVinci Resolve or After Effects.

**Cost for one video:** Recraft V4.1 4K ref 4 cr ($0.20) + Seed Audio 1.0 10 s MP3 12 cr ($0.60) + Seedance 2.5 10 s 1080p 90 cr ($4.50) + Genjutsu Object Swap 99 cr ($4.95) = **205 cr ($10.25)**.
