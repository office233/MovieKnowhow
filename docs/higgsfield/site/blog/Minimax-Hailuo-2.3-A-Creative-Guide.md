**Minimax Hailuo 2.3** — best known for **transformations** (human -> creature, product -> liquid/particles) with physics-driven morphing that tracks light/texture.
Improvements: depth/inertia-based physics (fabric, hair, particles); prompts control motion intensity, lighting transitions and transformation paths — verbs like "dissolve", "ignite", "shift into light" become physical behavior; embedding-level face/product/logo consistency; stable anime linework and color; sharp logos and on-screen typography through motion.
Settings on Higgsfield: **Fast 2.3** (iteration) vs **Standard 2.3** (final); duration **6 or 10 s**; **768p or 1080p**; aspect = input image; input image + optional text.
Presets: 70+ (Camera Control, UGC, Action Movement, Commercial, Viral, Emotion, Effects). Camera presets (dolly-in, pan, zoom, tilt, rotation) now with correct parallax — for product reveals, intros, hero shots. Presets are "motion blueprints" that react to your image and prompt.
Steps: Video -> Minimax 2.3 -> upload image (portrait, product, anime frame) -> optional short visual prompt -> preset -> Fast/Standard -> duration/resolution -> Generate.
Best practices: high-res clear image; **short, physical verbs** ("melt", "ignite", "morph"); match lighting between reference and goal.
