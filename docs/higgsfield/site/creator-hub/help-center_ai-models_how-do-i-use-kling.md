**Multi-shot workflow** (Video -> Kling)
1. Write each scene (action, setting, camera move, mood) as connected narrative beats.
2. Upload Start and End frames; reuse the last frame of scene N as start frame of scene N+1 for seamless chaining.
3. Add Elements to lock characters/products/objects across scenes.
4. Audio: SFX, speech, music synced (toggle off if not needed).
5. Genre: General, Action, Horror, Comedy, Noir, Drama, Epic. Speed ramp: Linear, Auto, Flash In/Out, Slow-mo, Bullet Time, Impact, Ramp Up.

**Motion Control inputs**: character image with arms and hands visible, space around the body, clear background + a clean motion reference video with a clear subject, framing matching the character image, and NO camera cuts. Good for dance, athletics, martial arts, jumps, weight shifts, hand articulation; you can change the environment by prompt while keeping motion. You can record yourself as the reference. Also available in MCP.

**Tips**: Turbo for drafts, full model for finals (queues are long on top models). Generation stuck >10 h -> contact support.
