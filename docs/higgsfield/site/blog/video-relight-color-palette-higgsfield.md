## Notes

**Topic:** Video Relight and Color Palette as standalone post tools (Aug 20 2026).
- **Video Relight:** re-renders lighting on an existing (generated or filmed) clip, keeping composition and motion. Presets: Practicals (visible in-frame sources), Silhouette (shape over detail), Contre-jour (backlit rim), Soft Cross (key-and-fill feel), Window, Overhead Fall, + Auto. Custom: up to **two lights** with colour, brightness, diffuse, angle — or describe them in a prompt (example below).
- **Color Palette:** applies a grade to an existing clip: 50+ presets (Film Colors warm-shadow cinematic, Black Gloss deep glossy blacks, Candy Pink & Lime Jam stylised, Nostalgic Blue, Soft Palette, Overtime, Crimson Vigi...) or a **reference image** to match.
- Uses: daytime shot must read as dusk; add a missing practical source; match light direction between generated and filmed clips; unify a series' look; test 5-6 grades quickly. Run Relight first then grade (order doesn't change the result but helps judging).
- Pricing: 15 s clip = 135 cr ($6.75) each tool.
- Use standalone tools for finished footage; Cinema Studio 4.0 when light/colour are set together with camera, lens, era during generation (same underlying systems).
