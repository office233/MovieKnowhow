## What it does

Generate new camera angles from a single photo

**Angles 2.0 (custom tool; image template `camera-angle`).** Rotate and tilt the virtual camera around a single image to get new viewpoints of the same scene while keeping details. **Technique:** generate reverse, side and high/low angles of one hero frame to build shot/reverse-shot coverage for a scene, then animate each angle as its own clip.
