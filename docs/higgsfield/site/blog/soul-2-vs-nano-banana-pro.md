## Notes

**Topic:** choosing between Soul 2.0 and Nano Banana Pro (Sep 8 2026).
| Axis | Soul 2.0 | Nano Banana Pro |
|---|---|---|
| Look | editorial, cinematic, fashion/culture-native | photorealistic, broad styles incl. illustration |
| Text in image | weak | reliable |
| Object editing | limited | strong, direct; multi-image fusion; pose control |
| Face over many generations | strong with Soul ID | drifts (no trained identity) |
| Crowds | weaker — trained face can clone onto background people | keeps crowds distinct |
| Resolution | up to 2K | up to 4K |
| Cost | 0.125 cr ($0.006) | 2K 2 cr, 4K 4 cr |
Controls: Soul 2.0 = 20+ presets, Soul HEX, Moodboard, Soul ID; NB Pro = plain-language prompts in any language.
**Pick:** quick single shot from a reference -> NB Pro; cinematic portrait/editorial -> Soul 2.0; packaging text -> NB Pro; recurring character series -> Soul 2.0 + Soul ID; stylised illustration -> NB Pro. **Combine:** establish character and aesthetic in Soul 2.0, then refine text/product details/object edits in NB Pro.
**Test result:** same prompt — Soul 2.0 followed the high-angle, asymmetric composition and props more closely; NB Pro kept the concept but simplified and symmetrised the layout.
**Tips:** one Moodboard per Soul series; Soul HEX instead of colour words; train Soul ID before a character series; be specific with NB Pro (subject, composition, action, location, style); give exact constraints (framing, camera details, **text in quotation marks**, things to avoid).
