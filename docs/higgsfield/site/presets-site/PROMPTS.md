# Presets-site — prompts

**Verbatim prompts extracted: 0.** None of the 123 pages (87 effect pages, the /effects listing, 33 Mixed Media preset pages, the Mixed Media intro and the community gallery) has a generation prompt. On every sample job `prompt` is `""` and `enhancedPrompt` / `systemPrompt` are `null`. These presets are prompt-template chains: the creative prompt is inside the preset and is not published.

What you *can* control is listed below: presets with a free-text input that goes to the chain's `user_prompt` port. Treat it as an optional steer (outfit, location, action detail). No defaults or examples are given, so keep it short and descriptive. Leave it empty to get the look shown in the preset preview.
