# Why was my generation blocked for copyright or IP?

Source: https://higgsfield.ai/creator-hub/help-center/troubleshooting/my-generation-blocked-for-copyright-or-ip
Published: Aug 1, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (troubleshooting). IP filter blocks named franchise characters (Disney, Marvel, DC, Pixar, Nintendo...), sports team/league names and branding (NBA, NFL, EPL), named living artists/photographers as style references, brand names/logos as subjects. Some models (e.g. Seedance) run an extra IP check. **Rephrase with visual descriptions instead of names** (examples in prompts file); replace branded reference images with neutral ones. Blocked credits usually refunded. For inputs you own, an "I own the rights for this image" button (bottom right of the generation) may unblock eligible inputs. Conservative by design; original content can be caught too.
