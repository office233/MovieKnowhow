## Notes

**Title on page:** "Cinema Studio 2.0: The Most Professional Cinematic AI Video Generator" (Feb 17 2026). No prompts; a feature + workflow guide.

**Philosophy — "Hero Frame First":** perfect the still (lighting, composition, character) before animating; the video strictly inherits the hero frame's look.

**Capabilities (2.0):** optical simulation (camera sensor, lens glass e.g. Cooke, focal length 8-50 mm, aperture/bokeh); deterministic camera moves (Pan Right, Tilt Up, Zoom In, Truck Left...); Start & End frames with auto in-betweens (e.g., start on a face, end on a landscape); auto/manual multishot; recommended + saved camera presets.

**Image-stage tools:**
- **3D Scene ("Enter the Set")**: after generating a key frame click "Create 3D scene", move the image across three axes and choose a new angle/key frame.
- **Grid exploration** 2x2 / 3x3 / 4x4 variations — quick comparison and a storyboard before animation.

**Video-stage tools:**
- Genres: Action, Horror, Comedy, Western, Suspense, Intimate, Spectacle (Musical), Auto — affects pacing, motion energy, camera behaviour.
- Multi-shot: up to **6 shots, 1-12 s per shot, 12 s total max, 1080p** (final size depends on start frame). Manual mode sets duration, camera move and slow-mo/speed ramp per shot.
- Characters: up to **3 per scene**, with per-character emotion and control over who appears in each shot. **Write dialogue explicitly** if a character must say something — otherwise the reasoning engine invents speech.
- Start/End frames work in single-shot and auto multi-shot; **End frame is disabled when characters are used** in auto or manual multi-shot.

**Step-by-step:** Phase 1 (hero frame): Cinema Studio 2.0 -> camera sensor, lens, focal length (8mm ultra-wide ... 50mm natural), aperture (wide for portraits/macro, narrow for landscapes) -> prompt scene/light/subject -> optional 3D scene / grid -> generate batch and pick. Phase 2 (motion): camera moves -> speed ramp (Slow-mo, Linear, Speed Up) -> single / auto multi-shot / manual multi-shot -> genre (or Auto) -> add character elements and write their dialogue referencing them -> generate.
