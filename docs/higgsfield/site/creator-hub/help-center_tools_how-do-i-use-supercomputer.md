# How do I use Supercomputer?

Source: https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-supercomputer
Published: Aug 1, 2026 (5 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (tool guide). Supercomputer = agentic chat workspace: plans multi-step tasks, routes each step to a generation model (Soul, Cinema Studio, Seedance, Nano Banana...), connects to external apps, assembles results.
- Start: Supercomputer -> describe the goal in plain language -> agent proposes plan -> runs -> refine by reply (only changed steps re-run).
- Chat LLM: auto-routing (cheaper/faster) or pick a model (Anthropic, OpenAI, Google, xAI, DeepSeek...).
- Connectors: Telegram, Slack, TikTok, Gmail, Google Drive, Notion and more.
- Sidebar: New chat/Search, Apps, Games, Skills, Connectors, Memory, Faceless channel (YouTube faceless videos up to 15 min; 12 visual styles; script, VO, 2D animation, music, subtitles).
- Official skills: Product UGC, Higgsfield Faceless Video, Shorts Maker, YouTube Covers, Personal Clipper; use cases TV Commercials, Animated Infographics, Localization. Community skills; My skills; Create new; skills also auto-built from chats; usable via MCP (Claude) and ChatGPT plugin.
- Credits: every generation step billed at standard rates; running cost shown; Unlimited never applies. Storage extendable via Manage Storage.
- Supercomputer (in Higgsfield web) vs MCP (inside your own assistant): both credits-only.
