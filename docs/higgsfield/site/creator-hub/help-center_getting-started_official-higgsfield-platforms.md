# What are the official Higgsfield platforms?

Source: https://higgsfield.ai/creator-hub/help-center/getting-started/official-higgsfield-platforms
Published: Sep 5, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (security). Official surfaces only: higgsfield.ai (sign-in, generation, payment), open.higgsfield.ai (API console), docs.higgsfield.ai, MCP (setup page higgsfield.ai/mcp; only connector URL mcp.higgsfield.ai/mcp), discord.com/invite/higgsfield, official X/Instagram/YouTube/LinkedIn/TikTok. No mobile or desktop app, not open source, no resellers/lifetime plans/transferable accounts. "Free Higgsfield" offers elsewhere are phishing. Report copies with link + screenshot; if credentials were entered on a copy, reset password and contact Support.
