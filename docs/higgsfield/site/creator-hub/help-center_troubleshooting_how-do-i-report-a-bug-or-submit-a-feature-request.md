# How do I report a bug or submit a feature request?

Published: Aug 1, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (troubleshooting). Bugs via contact page with browser/OS, screenshot or recording, expected vs actual, generation time/model/URL. Security issues privately to support@higgsfield.ai. Feature requests in Discord #suggestions: describe the workflow and friction, not just "I want X". No public roadmap.
