# Supercomputer home (/supercomputer)

Source: https://higgsfield.ai/supercomputer (app shell; canonical /supercomputer-intro). Product overview already in [../../features/tools/supercomputer.md](../../features/tools/supercomputer.md); this file records what the logged-out app home shows in Sep 2026.

## Layout
- Left rail: New chat (Ctrl+Enter), Projects, Skills, Connectors, Chats, Pricing (banner "30% OFF").
- Prompt box "What are we creating today?" with filter chips: All, Marketing, Explainer videos, Apps, Games; a **Free Mode** toggle is shown as a feature.
- Three card rows, each card has **Recreate** (loads the prompt into a new chat) and sometimes **Learn more**:
  1. Featured skills: Ad Multiplier, Editorial Motion Graphics, Higgsfield Faceless Video, Cartoon Faceless Video, SaaS UGC video, Physical UGC video, **Brandkit**, **Shorts Maker**, Website Building.
  2. **Higgsfield explainer** ("Turn any topic into a clear, visual explainer video") - nine visual-style presets: retro 8-bit pixel art, claymation, mixed-media collage, clean 2D flat, whiteboard doodle, low-poly 3D, polished 3D render, isometric flat vector, fluffy plush toy.
  3. **UGC videos** ("Turn any product into scroll-stopping creator content") - template families: This Gadget Saved Me, Giant Figure, Pro Virtual Try On, Virtual Try-On Sneakers, Couple Sharing At Home, UGC Virtual Try On, Unboxing Virtual Try-On.

## How to use these as templates
- Explainer: pick one style sentence, then append your topic ("...about why cats purr"). The style sentences are complete look descriptions (character material + background + shading + motion), which is the pattern to copy when you invent a new style.
- UGC: the card titles are named templates; the sentence after the colon is the scene (creator, location, product, payoff). Swap product and setting, keep the "problem -> product saves the day" beat for "This Gadget Saved Me".
