## Notes

**Topic:** producing 100+ ad creatives a month solo with Marketing Studio (Jul 17 2026). No prompts.
- Why volume: most ads fail and winners fatigue; constant angle/format/hook testing wins.
- Marketing Studio: paste product URL -> extracts images, name, features, pricing -> writes script -> spokesperson video with native audio + lip sync -> export. Video on Seedance 2.0 (up to 9 refs: product images, spokesperson face, VO clip, camera style). Formats: UGC, Tutorial, Unboxing, Product Review, TV Spot, Hyper Motion, Wild Card, UGC Virtual Try On, Pro Virtual Try On. Max 15 s; **~$2 per 8 s 720p clip** (100 clips ≈ $200).

**Workflow A — spokesperson-led:** train Soul ID once (Soul -> Train new character, 20+ photos) -> paste URL -> **write 5 scripts per product** for 5 angles (problem-solution, social proof, feature highlight, lifestyle, price-value) -> format (UGC and Product Review strongest for DTC on TikTok/Meta) -> attach Soul ID -> aspect (9:16 TikTok/Reels, 16:9 YouTube, 1:1 feed; each ratio is a separate generation) -> generate -> scale winners with **Ad Reference** (recreate a winning ad's concept, composition, pacing, hook with your product) and Virality Predictor.
**Workflow B — product-only:** URL -> benefit-focused short script -> Unboxing / Product Review / Hyper Motion / TV Spot (Tutorial for learning-curve products) -> skip spokesperson -> test 10 combos for ~$20 before scaling.
**Workflow C — high-volume UGC aesthetics/statics:** multiple visual refs -> UGC or Wild Card -> set **Hook** (attention mechanic) and **Setting** (location/vibe) separately — these are an *alternative* to Ad Reference (use one or the other) -> DTC Ads for statics.

**Weekly rhythm (25/week):** Mon 5 variations of a new angle; Tue 5 in a different format; Wed review last week's data; Thu 5 variations of the winner (new hooks); Fri 10 variations of the top format via Ad Reference.
**Limits:** 15 s max (assemble longer ads in post); web UI (automation via MCP); statics via image tools/DTC Ads.
