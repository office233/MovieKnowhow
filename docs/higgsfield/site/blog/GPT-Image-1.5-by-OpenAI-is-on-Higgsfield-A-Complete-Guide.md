**GPT Image 1.5** (referred to in-page by codename "Hazelnut") — a structure/reasoning-oriented image model, not a high-fidelity art model.
Specs on Higgsfield: up to ~1.5K resolution; quality Low (fast previews) / Medium / High (final); aspect ratios 1:1, 2:3, 3:2. Inputs: text only, or multimodal with up to 5–6 reference images (sketches, diagrams, charts, screenshots).
Strengths: layout and spatial relationships, labels/proportions, information flow, hierarchy — infographics, diagrams, concept visualization, merging sketches/wireframes into one clean output; consistent, low-hallucination.
Steps: Image -> pick the model -> choose multimodal or text-only -> upload only helpful refs -> write a structured prompt (describe intended structure and relations between inputs) -> quality -> aspect ratio -> Generate.
Film use: good for storyboard/shot-plan sheets, labeled diagrams, text-heavy frames; use other models (Soul, Nano Banana) for photoreal art.
