Why human motion is hard: weight must load before an action and release after; fabric must respond; micro-expressions on the right beats; all consistent frame to frame.
**Cinema Studio as "direction, not model quality"** — controls applied before generation:
- **7 genres**: General, Action, Epic, Drama, Comedy, Horror, Noir (change physical logic: Action = kinetic tension, Drama = slower weighted movement, Noir = shadow logic, restrained posture).
- **9 color palettes** incl. Auto, Naturalistic Clean, Bleached Warm, Hyper Neon.
- **7 lighting presets** incl. Soft Cross, Overhead Fall, Contre Jour.
- **10 camera moveset styles** incl. Classic Static, Silent Machine, Epic Scale (camera and subject motion generated together).
- **Lenses**: e.g. Vintage Spherical (optical breathing — feels captured), Modern Anamorphic (prestige horizontal stretch).
- **Montage pacing**: Chaotic, Dynamic, Calm, Single Shot. **Emotion control** sets the performance arc (e.g. Intense -> Explosive) so it's built into the motion from frame one.
- Multi-model inside: Kling 3.0, Veo 3.1, Seedance 2.0; clips up to 60 s (per this article); needs detailed prompts for specific motion. ~$3.23 per 15 s 720p.
Model notes: **Kling 3.0 = best raw human motion** (body, micro-expressions, gesture timing, fabric) ~$1.55/15 s; **Veo 3.1** best when environment matters + native audio, trails Kling on close human shots; **Runway Gen-4.5** best prompt adherence/most controllable (Motion Brush, Act-One), less organic; HeyGen/Synthesia presenter-only; Creatify moderate.
