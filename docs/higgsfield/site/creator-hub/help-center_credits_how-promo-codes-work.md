# How do promocodes work?

Source: https://higgsfield.ai/creator-hub/help-center/credits/how-promo-codes-work
Published: Aug 3, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (credits). Redeem in Manage Account -> Promocode -> Enter code (instant). Promo credits expire on shown date; survive cancellation. Sources: official socials (first), Discord events; Support promos are discretionary and must be activated within 7 days. One activation per code.
