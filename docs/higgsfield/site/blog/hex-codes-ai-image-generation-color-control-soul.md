## Notes

**Topic:** colour control with HEX codes and Soul HEX (Feb 23 2026). No prompts.
- HEX = #RRGGBB, each pair 00-FF for red/green/blue (#FF0000 red, #000000 black, #FFFFFF white).
- Models differ: some read HEX codes natively, some ignore them, some treat them as loose guidance. Describing colour in words is unreliable ("warm gold" -> mustard, "soft teal" -> aquamarine).
- **Soul HEX** (in Soul 2.0, "Color signature" section): upload **1-20 reference photos** whose colours you want; optionally choose a Soul ID character and a preset (or none / "General"); generate — palette is extracted and applied automatically.
- Uses: carry a mood (rainy blues, golden-hour amber) through colour alone; match brand palette from an existing branded asset; lift a grade from an image you love; keep a campaign/series cohesive from one reference; when you can't name the shade.
- Related tip seen elsewhere in this crawl: long location prompts can end with an explicit HEX palette list (see guide-youtube-seedance2.0).
