Previs levels: storyboard (framing, positions, light direction) -> animatic (timing, motion) -> 3D previs (geometrically accurate blocking). Changing a shot in planning costs nothing.
**Popcorn + Cinema Studio quick start**:
1. Create -> Image -> Popcorn.
2. References: clear character portrait (face must hold) + location ref.
3. Prompt: **lead with style ("Cinematic photorealistic")**, then who, where, what happens across the sequence, emotional register.
4. Up to 4 refs; frame count **4 = simple, 6 = clear arc, 8 = complex multi-beat**.
5. Check consistency, lighting logic, whether camera positions/emotion read.
6. Feed frames into **Cinema Studio as reference inputs**; set per-shot genre, lighting, lens, focal length, aperture, camera movement -> actual cinematic video.
Other tools: Katalist (script -> storyboard -> animatic -> video; Premiere export), LTX Studio (script to export, 2D/3D animatics), Runway Story Panels (one image -> connected shots; Cinematic Brainstorm = 9 variations), **ShotDeck** (36M+ tagged real film stills — lens, lighting, film stock; great for building a reference/look deck), HeyGen (presenter previs), DrawStory (sketch boards, cost shown upfront), Blender (accurate 3D blocking, overhead floor plans).
