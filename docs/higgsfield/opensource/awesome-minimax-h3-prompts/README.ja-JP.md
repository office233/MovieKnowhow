### 2.1. 夕暮れのキッチンに宿る手描きの光

*生活感あるキッチンでスマートフォン実写と発光する手描き生物を融合。*

**プロンプト:**

```text
15秒、16:9横位置。夕暮れの小さなキッチンの実写映像と、手描きの発光アニメーションを融合する。窓には最後の夕日が残る。生活感のあるキッチンには古い木のテーブル、洗いかけのマグ、少し曇ったガラス瓶、吊り下げられた布巾がある。

誰かが片手でスマートフォンを持って撮影したようにする。微かな手ぶれ、ためらうような近距離のフォーカス送り、逆光による露出の呼吸、影のやや粗いノイズ。慎重に演出されたCMではなく、自宅で驚くべき出来事を慌てて記録した感覚にする。

巨大な目、裂けた口、牙、威嚇行動、飛びかかり、突然の黒フレーム、ジャンプスケアを見せない。音は室内音、布の摩擦、控えめなマグの触れ合う音、蛇口の滴、撮影者の足音と静かな呼吸、そして描かれた生き物の穏やかな電子音と小さな声だけを使う。
```
