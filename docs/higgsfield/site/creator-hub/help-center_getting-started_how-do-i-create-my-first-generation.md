# How do I create my first generation?

Source: https://higgsfield.ai/creator-hub/help-center/getting-started/how-do-i-create-my-first-generation
Published: Jul 30, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (first steps). Top nav Image or Video -> choose model/feature (or default) -> prompt -> optional reference image -> settings (duration, aspect ratio, resolution) -> Generate. Result appears in the tool and in Assets. Typical time: a few minutes (images faster; high-res video slower). Two example prompts are given (see below; video example uses the generic /generate route, image example links to Soul Cinema).

## Prompts (verbatim)
