# Which Higgsfield tool should I use?

Source: https://higgsfield.ai/creator-hub/help-center/tools/which-higgsfield-tool-should-i-use
Published: Aug 1, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (tool chooser).
| Goal | Tool |
|---|---|
| cinematic video with camera control | Cinema Studio |
| consistent characters across clips | Cinema Studio + Soul ID |
| product ad from URL/image; UGC ads at scale; A/B variants; replicate viral ad format | Marketing Studio |
| consistent AI influencer / non-human character; faceless creator business | AI Influencer |
| chain models, team real-time collaboration, reusable templates | Canvas |
| whole project from one chat; scheduled recurring content; websites | Supercomputer |
| generate from Claude | MCP |
| generate from a coding agent | CLI + Skills |
Typical combo: build character in AI Influencer -> scenes in Cinema Studio -> scale variations with Supercomputer. Use Marketing Studio for fast product ads, Cinema Studio when you need control over scene, camera, characters. MCP/CLI still require an active subscription.
