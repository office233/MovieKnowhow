# Add Director-Style Cinematic Lighting with Relight

Source: https://higgsfield.ai/blog/Relight-Director-Style-Cinematic-Lighting  
Mariam Barova, Jan 6, 2026  
Prompts extracted: 0

**Relight** re-lights a still using depth-mapping (understands 3D geometry), controlling angle, intensity, color and quality of a virtual light.
Controls:
- **Quick Select grid**: Top, Front, Right, Left, Back, Bottom. Front = beauty light; Back = rim light/halo.
- **Light Direction Pad**: drag a 3D light cone for off-axis setups (e.g. above-left for a Rembrandt look).
- **Soft vs Hard**: Soft = softbox/window wrap, gentle falloff; Hard = sun/flash, crisp shadows and high contrast (edgy fashion, noir).
- **Brightness** 0–100% (default 50%). **Color** hex input (default #FFFFFF) — e.g. orange streetlamp, blue TV glow, neon pink/blue for cyberpunk.
Steps: upload -> Relight tab -> pick preset or drag pad -> Soft/Hard -> brightness/color -> Generate (seconds).
Use-cases: rescue backlit selfies (front light without blowing background), product shots (top/side light for depth/texture), stylized moods. Useful for matching lighting of start frames across a sequence before animating.
