# What's in my Higgsfield account?

Source: https://higgsfield.ai/creator-hub/help-center/getting-started/whats-in-my-higgsfield-account
Published: Jul 30, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (account UI).
- Account menu (avatar): credits, Top-up credits, Boost speed / Increase Concurrent (both = Concurrency Boost), Unlimited models, View profile, Manage Account, Join Community, Sign Out.
- Manage Account (higgsfield.ai/me/settings): Personal profile, Gifts, Subscription, Usage, Promocode; balance + Top-up, usage chart, Collab karma history.
- Public profile higgsfield.ai/@username (All works, Projects, Generations).
- **Assets** (higgsfield.ai/asset/all): every generation saved; filter Image/Video/Audio; folders, Favorites, search. Asset view: copy the prompt, see model/resolution/date; edit (Color Grading, Upscale, Enhancer, Relight, Inpaint, Angles); **Turn to video**, **Recreate** (rerun same prompt), **Reference** (use as input); download/share; comments; bulk actions; three-dot -> Publish or **Create Element** (reusable reference). Generation ID = last part of the asset URL.
- Team: owners/admins can see members' assets. Canceling does not delete assets.
