# Can I get a refund for a subscription I never used?

Source: https://higgsfield.ai/creator-hub/help-center/refunds/can-i-get-a-refund-for-a-subscription-i-never-used
Published: Aug 1, 2026 (1 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (refunds). "Unused" is measured by credits spent (logging in/browsing doesn't count; Unlimited and free gens don't count). Conditions: initial purchase, within 7 days (or local law), zero credits used; fee up to 6%; subscription canceled immediately on approval. Any credit use = no refund.
