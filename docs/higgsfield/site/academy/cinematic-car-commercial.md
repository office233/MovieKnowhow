# Direct a cinematic AI car commercial

- **URL:** https://higgsfield.ai/academy/courses/cinematic-car-commercial
- **Taught by:** Higgsfield Creative (presenter/driver: Adil)
- **Level:** Intermediate · **Modules:** 11 · **Duration:** 35 min
- **Description (paraphrased):** build a cinematic car commercial (red sports sedan; driver in disguise gives a traveler a ride from dealership → gas station → downtown → toll → airport) from reusable named assets, controlled iterations and continuity-aware editing.
- **Skills:** build named product/character/prop/location assets into stable source frames; diagnose failures in performance, physics, blocking, identity and geography; assemble selected moments into a coherent commercial and judge the cut.
- **Tools named:** Cinema Studio (video), Soul Cinema (natural performance/atmosphere images), Seedream 5.0 Pro and Nano Banana Pro (reference-based image edits compared), an image editor for manual cleanup, Claude + a downloadable "Seedance prompt generator" skill (lesson 3 resource) that expands beat descriptions into full prompts.
- **Official prompt format (all video prompts):** `— REFERENCE DEFINITIONS —` (each `@element`: appearance description + "… reference only. Reference.") → `— TECHNICAL BLOCK —` (Cinematic photoreal. 16:9. N s. SFX only / dialogue language. Natural grain, organic color, soft contrast, filmic look. NO CGI. NON-IP. Exact shot/cut count) → `— PROMPT —` (numbered SHOTs with durations, blocking, performance micro-direction, quoted dialogue, closing SFX line). Durations used: 4 s, 8 s, 10 s, 12 s, 13 s, 15 s.

## Lesson 1 — Plan around reusable assets
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/plan-around-reusable-assets
- Second viewing: ignore story, count what must survive shot to shot (car, driver in two looks, traveler, consultant, key, locations).
- Dependency list: one row per returning visual with stable name, approved reference, dependent scenes. Product saved as `@car_sheet`, and Claude is told the same name.

| Asset class | Lock | Protects |
|---|---|---|
| Product | shape, paint, badges, cabin | exterior/interior/beauty continuity |
| Character | face, wardrobe, role variants | identity across cuts |
| Prop | key, disguise pieces, newspaper | readable actions in motion |
| Location | palette, geometry, clean plate | geography, stable backgrounds |

- Folders: one per scene → asset-type subfolders → new subfolder per iteration (winning take recoverable after hundreds of attempts).
- Start product references on neutral grey to isolate the object before making it an element.
- Gate: every returning visual has one approved reference + one stable name.

## Lesson 2 — Build characters for continuity
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/build-characters-for-continuity
- The trophy image failed (smooth face, staged pose, too clean) even with a strong driver sheet; reference edits (Seedream 5.0 Pro / Nano Banana Pro compared) held identity but not a lived-in performance.
- Split the jobs: **Soul Cinema** generates natural expression/atmosphere → separate **face-swap** pass restores the approved driver.
- Removable mustache is designed as a fake prop because a later scene has the driver peel it off — wardrobe must support future actions.
- Consultant's close-up and full-body faces conflicted → removed the full-body face in an image editor; keep the strongest face as identity source and let headless outfit views carry wardrobe.
- Name each pass's job (sheet = identity + clothes; Soul Cinema = celebration; edit = join; disguise sheet = story state) so you can fix one without reopening others. Every `@tag` needs a matching named element in your project.

## Lesson 3 — Assemble a scene from locked references

- Find palette first with a loose "vibe" dealership prompt in Cinema Studio (4 candidates), then transfer that color to a detailed pass resolving architecture (glass wall, orange feature wall, space for the champion photo) before anything moves.
- With showroom, characters, car, key locked, describe the scene beat by beat to the skill.
- Judge batches at shot level: final dealership scene = opening from video 1, wide from video 2, key shot from video 3, rest from the last generation. Ask which beat worked and where it starts/stops — those are edit points.

## Lesson 4 — Cast and clean the plate
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/cast-and-clean-the-plate
- Casting is continuity: of three stable traveler sheets, one read as villain, one as a side character; the third (natural skin, soft light, wardrobe) became lead.
- Gas-station plate had text, clutter, distant cars; first motion test showed background cars turning into clones of the red hero car. Two edit passes: remove text first, then distant cars.
- Label every background detail **safe / risky / unnecessary**; test in motion before calling the plate finished.
- Kept stop: traveler braces eyes shut, bumper dives close to her knees, awkward pause with hands raised.

## Lesson 5 — Repair continuity with references
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/repair-continuity-with-references
- Showroom exit → gas station felt like a teleport; fix with a bridge shot showing distance covered (a new residential street, not the gas-station plate which would spoil the destination). Only first/last shots of the winning drive kept; low wheel angle survived, aerial over traffic kept breaking.
- **Derive matching stills from one motion source:** generate one continuous "statics" video of parked car/cabin/steering wheel, pause on frames and save them as elements (consistent light and detail vs separate image gens). Name frames by job (blocking frame, wheel frame).

## Lesson 6 — Direct dialogue through selection
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/direct-dialogue-through-selection

Keep a **take ledger**: selected fragment → the one job it solves → what's discarded (opening angle; mirror close-up of doubt; mustache peel; glasses removal; control & pedal inserts; traveler reaction pinned with a gasp).
- Timeline revealed disguise came off too fast → give the joke breathing room. After the disguise is gone, switch prompts to the clean hero reference.
- Selection test: "I am keeping this because it supplies ___."

## Lesson 7 — Make complex driving readable
URL: https://higgsfield.ai/academy/courses/cinematic-car-commercial/make-complex-driving-readable
- Six ambitious downtown shots failed: traffic lights contradict cars, aerial traffic crosses lanes, dense overtakes lose order. Fix = smaller visible problem: frame out the intersection, reduce visible traffic.
- Cabin: start with a plain frontal view (driver front, traveler back, both belted) so later angles inherit the arrangement; attach front-cabin and rear-bench references derived earlier.
- Build around what survives: highway dashboard shot broke, but the wind-blast shot (car whips past, camera reacts) worked every time → rebuilt the speed sequence around it.
- Pair every rejected setup with the complexity it exposed ("the aerial exposed all lanes at once").
```text
— REFERENCE DEFINITIONS — @hero_03: Young man in his mid-20s, mixed Asian features, dark curly hair, small silver hoop earrings, wearing a worn brown suede jacket over a cream crew-neck t-shirt.
```
