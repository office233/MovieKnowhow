# How do I use Marketing Studio to create video ads?

Source: https://higgsfield.ai/creator-hub/help-center/tools/how-do-i-use-marketing-studio-to-create-video-ads
Published: Aug 1, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (tool guide). Marketing Studio = template-first ad creation (1,500+ templates), no prompt required.

**Flow**: Marketing Studio -> pick template -> connect brand (upload product image OR paste website/product URL; logo, colors, copy and imagery are auto-extracted) -> Generate (one click; cost on button).
**Template categories**
| Category | Output |
|---|---|
| Product Shots | Studio (seamless catalog), Lifestyle (real scene), With Model (held/worn/used) |
| Ads | image ads to Meta/Google placement specs |
| Marketplace | listing imagery |
| Posters | banners/posters editable after generation via Layers |
| UGC Videos | phone-shot creator ads: Faceless, Talking Head, Silent (input: product image or a reference ad) |
| Motion | Hypermotion, 2D Product Motion, Mixed Media, Motion Design (from logo or website: good for software/digital products) |
| Ref -> Video | video from a reference |

**Features**: prompt path for unusual products; clone an existing ad's structure in UGC Videos by dropping in a reference ad you're allowed to use; **Virality Predictor** scores virality, engagement and attention-holding to choose among variants (estimate only); **Brand Kit** from website URL (logo, colors, fonts, imagery, tone); same spokesperson across all variations via Soul ID (20+ photos).
**Limits**: max 15 s per clip; UGC voiceover/pacing vary, review before publishing; only Posters are editable post-generation (others regenerate); template Marketing Studio not available in Supercomputer/MCP yet. If URL extraction fails, upload product images or use prompt path.
