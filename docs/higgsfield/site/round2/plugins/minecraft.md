# Higgsfield inside Minecraft (Higgscraft mod)

Source: https://higgsfield.ai/plugins/minecraft

## Notes

- Unofficial mod for **Minecraft Java 1.21.1 + NeoForge** (CurseForge or drop the .jar in `mods/`). Sign in with `/higgsfield auth` in chat - no API key.
- New craftable blocks/items: **Supercomputer** (core block: prompt -> images, video, builds; shows balance and estimated cost), **Video Projector / Video Screen**, **Camera** (captures in-game views with zoom as reference images), **Generation Archive**, **Photo Slide** (holds an image, hangs like a painting), **Film Roll** (holds a video clip).
- Prompt-to-build materialises structures block by block where you stand; video is generated with **Kling 3**.
- Costs quoted in the FAQ: images about **1 credit**, video about **450 credits per clip**; video takes a few minutes. Results appear in the Supercomputer's output slot, not in your hand. Photo Slides and Film Rolls are required media and rewritable.
