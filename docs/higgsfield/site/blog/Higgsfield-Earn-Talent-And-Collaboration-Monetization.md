**Higgsfield Earn** = performance-based paid campaigns for creators (post content, get paid; no follower threshold stated).
Instagram flow: open Earn -> log in (account auto-created) -> My Accounts -> add IG handle -> paste the unique verification code (e.g. "HF-47392") anywhere visible in your bio -> "Verify My Account" -> browse Active Campaigns (each shows type, requirements, earnings structure, duration, guidelines) -> join -> post; performance tracked automatically from go-live -> live earnings dashboard.
YouTube flow: same, code goes in channel description. Only **one** YouTube account can be linked and it cannot be changed later. If "does not qualify", the account is kept and you're notified when a campaign matches.
Campaign page: exact payout, requirements checklist (links, hashtags, media kit), deadline, "Submit Your Video", sometimes "Generate Your Promo Code" (for campaigns requiring subscriptions/generations).
Payouts: withdraw anytime via **Garna** (same email; email + quick verification).
