# ByteDance Seedream 5.0 (Lite / Flash / Pro)

Sources: https://higgsfield.ai/seedream-5.0 (5.0 Lite), https://higgsfield.ai/seedream-5.0-pro

## Seedream 5.0 Lite
- "Thinks before it draws": real-time web retrieval (current events/trends), multi-step logical reasoning (physics, spatial relations), up to 4K.
- **Example-based editing**: give a before/after pair, then a new image - it learns and applies the transformation (style transfer, grading, object manipulation) without prompt engineering.

## Seedream 5.0 Pro
- Deep-thinking generation, automatic web grounding for time-sensitive prompts, instruction-precise one-sentence edits (change one prop/colour/label, rest unchanged, no masks).
- One-pass infographics (charts, flowcharts, annotated diagrams with legible small text).
- Native text in 14 languages (Arabic RTL, Thai tone marks, Cyrillic...).
- Up to 2K output (page elsewhere says 4K). Use as a "perfect first frame" then send to video on Higgsfield.
- Commercial use allowed.
- Showcase prompts (verbatim below) follow: **subject + wardrobe -> setting -> light -> palette -> lens/film stock -> finish**, and several reserve **negative space for headline text** ("dark sky for text", "vast negative space at top for headline text") - a useful trick for poster/thumbnail key art.
- Seedream 5.0 Flash = fastest reasoning variant; Seedream 4.5 = older 4K model.
