# Higgsfield Popcorn - AI storyboard generator (Keyframes)

Source: https://higgsfield.ai/storyboard-generator

- Generates up to **8 consistent scenes** per sequence (widget defaults: Output 8 scenes, 16:9, Quality High). Templates: Movie Story, Animated Movie, Motivational, Product Promo, or your own.
- Flow: optional image reference (style/character/product) -> write a prompt **per scene** (framing, motion, mood) -> generate aligned keyframes (same characters, lighting, tone).
- **Limitless story**: take the last image of a sequence as the new reference to continue indefinitely.
- **Multi-angle shots**: new camera angles/lighting of the same character or product.
- Built-in edit suite: relight, style swap, clothes change, face swap on any frame.
- **One-click export to Sora 2**: converts the approved keyframes into a ready Sora prompt/animated sequence.
- Use cases: storyboarding rhythm/angles/action beats, turn-to-video with Sora 2, product placement inside action scenes. Free daily credits let you test.
