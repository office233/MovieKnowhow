## Notes

**Topic:** Higgsfield Popcorn for consistent storyboards/image sequences + Soul ID for video (Jun 30 2026). Largely promotional; no prompts.
- Problems in sequences: character drift, lighting mismatch, stylistic inconsistency — single-image models have no memory between prompts.
- **Popcorn** features: multi-frame awareness (generates frames as a connected sequence), visual memory of face/clothing texture/light direction, locked lighting/style ("style coherence"), character anchoring from an uploaded reference, editable consistency (change light/background/composition after generation without breaking continuity). Popcorn exports to **Sora 2** for animation; for multi-model video pair Popcorn previs with Soul ID.
- Popcorn = consistency within a session's frames; Soul ID = trained identity across sessions and models.
- Use cases: previs storyboards with a fixed cast, ad campaigns with identical model/product across frames, connected social posts, product visualisation in many scenes.
- When not to use Higgsfield (their own list): multilingual presenter videos at scale -> HeyGen Avatar IV (175+ languages, Digital Twin from 15-min recording) or Synthesia (240+ avatars, 30+ languages); cheapest single-model clips -> Kling native; image-only design -> Magnific; one-off clip with no recurring character (Soul ID's 20+ photos not worth it).
