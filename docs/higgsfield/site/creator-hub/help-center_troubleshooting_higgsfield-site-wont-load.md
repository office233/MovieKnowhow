# What should I do if the Higgsfield site won't load?

Source: https://higgsfield.ai/creator-hub/help-center/troubleshooting/higgsfield-site-wont-load
Published: Aug 1, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (troubleshooting). Refresh -> hard refresh (Ctrl/Cmd+Shift+R) -> incognito -> other browser -> clear cache/cookies -> disable extensions (ad blockers, VPN, privacy) -> check connection. Download button dead: disable blockers, allow automatic downloads in browser settings, or use Chrome/Safari. Canvas/Supercomputer freeze: hard refresh (Canvas autosaves). Platform-wide outages announced in Discord #announcements.
