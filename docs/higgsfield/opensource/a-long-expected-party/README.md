# A Long-Expected Party

An interactive procedural short film rendered live in the browser with Three.js. The landscape, village, weather, crowd, and fireworks are generated in real time, accompanied by an original score, environmental sound design, and narration generated with Higgsfield.

## Live website

https://mengto.github.io/a-long-expected-party/

## Features

- Eight cinematic chapters across a 136-second timeline
- Procedural WebGL terrain, grass, trees, village, atmosphere, and fireworks
- Original score with chapter-specific environmental sound effects
- Seventeen synchronized narration cues
- Play, pause, restart, timeline seeking, chapter shortcuts, and persistent mute state
- Runs as a static website with no build step

## Run locally

Serve the repository with any static file server, then open the local URL:

```sh
python3 -m http.server 4173
```

## Audio

The score, environmental sound effects, and narration were generated through Higgsfield. The browser transport keeps all three audio layers synchronized to the visual timeline and ducks music and ambience beneath spoken cues.
