# AI Motion Designer: Higgsfield Meets After Effects Through GPT

Source: https://higgsfield.ai/blog/ai-motion-designer-after-effects-gpt  
Higgsfield, Sep 10, 2026  
Prompts extracted: 0

**AI Motion Designer** = an agent that connects Higgsfield generation to an open Adobe After Effects project via ChatGPT (also via Higgsfield MCP from Claude, Cursor, etc.).
Setup:
1. Add the Higgsfield plugin in ChatGPT.
2. Type `/use-after-effects` (e.g. "/use-after-effects build a logo reveal").
3. Describe the motion-graphics task in plain language; it builds layers, keyframes, timing and expressions in the open comp.
Notes:
- No fixed caps on resolution (1080p/4K/8K per prompt), runtime, or number of reference images/videos — only generation time increases.
- Requires Higgsfield + ChatGPT + After Effects subscriptions; Higgsfield generations bill at normal credit rates.
- Output layers are native, fully editable AE elements; it uses your own footage, text and brand colors.
Use-cases: title animations, logo reveals, transitions, product promos, recreating an animation from a reference, generating expressions. No AE knowledge needed.
