**Grok Imagine** (xAI) on Higgsfield — where it is strongest:
1. **Native voiceover/narration** with strong script adherence (keeps emphasis and structure; not flat) — explainers, micro-stories, branded storytelling, edu clips without recording VO.
2. **Facial expressions** that track emotional context (focus, surprise, calm, tension) without uncanny exaggeration — reaction shots, emotional beats.
3. **Physical interactions** — weight, grounded collisions, plausible absurd physics (animals slipping/falling) — good for comedic/viral clips.
4. **Motivated camera movement** — smooth pans/tilts, slow push-ins for emphasis, tracking shots, stable framing without jitter.
5. **Framing discipline** — holds focus on subject, avoids awkward crops; helps multi-shot cohesion.
Best fit: short/medium voice-driven narrative, emotional scenes, social/marketing content. Inputs: text prompt + optional reference image; output adapted to vertical / horizontal / square.
Steps: Video Generation -> choose Grok -> prompt + reference image -> Generate -> preview.
