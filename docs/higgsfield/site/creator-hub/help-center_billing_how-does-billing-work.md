# How does billing work?

Source: https://higgsfield.ai/creator-hub/help-center/billing/how-does-billing-work
Published: Aug 1, 2026 (4 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (billing). Payments via Stripe: cards (Visa, Mastercard, Amex, JCB), Apple Pay, supported bank payments. Prices exclude local tax (added at checkout). Auto-renew on the same calendar date. Unexpected charges usually = renewal, prorated upgrade, pack/Auto-Refill, tax, promo expiry, or a second account on the same card. Manage payment methods and billing address in Manage Account -> Subscription.
