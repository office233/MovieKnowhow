# Mastering AI Character Consistency in Video and Images | Soul ID

**Soul ID** = trained identity layer applied to anything generated in **Soul 2.0** (face stays, everything else changes).
Training:
1. Upload **20+ photos** of one person — high quality, consistent lighting, varied angles and expressions.
2. Train (~**3–5 minutes**). 3. Name it. 4. Generate: pick it in the **"Character" tab** of Soul 2.0; steer with presets + optional prompt tweaks.
Photo set rules: no sunglasses, heavy shadows or cropped faces; include **at least one full-height photo** (body proportions); **recent photos (last 4–5 months)**; quality over quantity.
Presets tuned to Soul ID (20+): Warm Ambient, General, Retro BW, Y2K Street, Subtle Flash, Y2K Studio, Street Photography, Theatrical Light, Asian Nostalgia, Editorial Street Style, Surreal Solarization, Flash Editorial, Digital Camera, Siren, Swag Era, Mystique City, Candy Pop, 2000s Band, Frutiger Aero, Drain, Old Smartphone. Presets beat freehand prompting.
Comparison: re-prompting drifts every time; per-generation reference image (e.g. Midjourney Omni Reference) still drifts over many generations; self-trained LoRA is reusable but technical. Soul ID = train once, no setup, but lives only inside Higgsfield (not exportable).
Limits: garbage in/garbage out; overkill for a single throwaway image; "clearly same person", not pixel-identical — extreme style shifts/odd angles can drift; old photos pull toward old appearance.
For invented (non-real) characters use **AI Influencer Studio** instead. Commercial use OK (lookbooks, Marketing Studio product shots, personal branding).
