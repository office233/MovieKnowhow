# Higgsfield Explainer (long-form narrated 2D)

Source: https://higgsfield.ai/explainer-intro

- Turns a script/outline into a **narrated 2D video up to 10 minutes** with one consistent narrator voice, the same characters and one art style throughout ("zero drift").
- **Dual export**: 9:16 and 16:9 from a single render.
- Available in the visual studio, inside Supercomputer (agent plans shots, writes narration, renders), or via Higgsfield MCP.
- Use: episodic social series, bedtime stories, brand/product explainers, audiobooks, short films.
- Style presets used by the Supercomputer explainer (verbatim prompts in tools/supercomputer.md prompts / PROMPTS.md): 8-bit pixel art, claymation, mixed-media collage, 2D flat illustration, whiteboard doodle, low-poly 3D, polished 3D, isometric vector, plush toy.
- Workflow: write story -> pick voice -> set tone, characters, 2D style -> generate -> export both formats.
