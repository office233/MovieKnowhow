## Notes

**Topic:** Higgsfield plugin for Adobe After Effects + Premiere Pro (Jul 21 2026). No prompts.

**Panel (Window -> Extensions -> Higgsfield AI), one installer for AE + Premiere:** Generate AI Video (prompt -> clip straight into the timeline), Generate AI Image (backgrounds, overlays, title cards), Reframe (9:16, 16:9, 4:3, 3:4, 21:9, 1:1 with subject tracking), Remove Background (no green screen, hair detail, alpha), Draw to Edit (brush on frame to remove/add/replace), Upscale (to 4K/8K with detail recovery), Edit Video (prompt-based change to existing footage).
**Why:** a generated background plate normally costs 5-10 min per browser round trip; in-panel you generate with a lighting description matching your plate and regenerate in place.
**Agent control:** via Supercomputer (auto-detects the plugin) or Claude via MCP using the **bridge URL `bridge.higgsfield.ai/mcp`** (the normal MCP endpoint generates assets but can't drive AE). The agent can build effects/animations from a description, recreate a design from an image or an animation from a video reference, write expressions from plain language (light streak, logo reveal with specific easing, camera-shake expression), import generations into the comp.
**Install:** macOS .dmg from higgsfield.ai/plugins/after-effects (universal binary); Windows via free ZXP Installer (aescripts) + .zxp. Requires After Effects 2024 (24.0)+, Win 10/11 64-bit or macOS, internet. Troubleshoot: quit Adobe fully before installing, run ZXP Installer as admin, check macOS Privacy & Security.
**Cost:** same credits as web, no markup; models on your plan's Unlimited list stay unlimited through the plugin (per this article). Separate plugins exist for Photoshop, DaVinci Resolve, Figma.
