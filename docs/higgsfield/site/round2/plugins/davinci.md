# Higgsfield plugins for DaVinci Resolve

Source: https://higgsfield.ai/plugins/davinci

## Notes

- Requirements: DaVinci Resolve 19+ (macOS and Windows). **Not compatible with the Mac App Store build** - use the Blackmagic download.
- Install: macOS `.pkg` (page text) / FAQ says `.dmg` for macOS and `.exe` for Windows; the installer adds Higgsfield to Resolve automatically. Open via **Workspace -> Workflow Integrations -> Higgsfield** (FAQ also says Workspace -> Scripts -> Higgsfield). Panel is dockable.
- Seven tools: **AI LUT creator** (match a look from one reference frame/photo/palette - recolours footage to the reference's tones, contrast and mood), Generate AI Video, Generate AI Image, Reframe, Remove Background, Draw to edit, Upscale (to 4K/8K); the FAQ lists Edit Video instead of the LUT creator. Results go to the media pool.
- Cinema Studio 3.5 panel inside Resolve (same demo as Premiere).
- Related: grading skill [../../mcp/color-grading.md](../../mcp/color-grading.md); existing blog note [../../blog/higgsfield-davinci-resolve.md](../../blog/higgsfield-davinci-resolve.md).
