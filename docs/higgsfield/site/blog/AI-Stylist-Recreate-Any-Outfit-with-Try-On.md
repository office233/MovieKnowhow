**AI Stylist** (Apps) — modular virtual try-on: upload a photo, apply a full outfit preset or build it piece by piece, then set pose and background presets.
Path: Higgsfield -> Apps -> AI Stylist -> upload image.
1. Styling approach: (A) ready **outfit preset** for speed/moodboards; (B) **by category** — Headwear, Outerwear, Base (tops), Pants, Footwear, Accessories — for control (keep base consistent with brand palette, iterate one category at a time).
2. **Pose preset** — casual / editorial / product-forward body language without a new source photo.
3. **Background preset** — clean minimal backdrops highlight the outfit; textured/location backdrops add narrative/lifestyle energy.
Tips: clean, well-lit, non-blurry input; change one element per iteration; match pose to vibe; choose backgrounds with intent.
Ad use: rotate outfits with fixed pose/background (or vice versa) to spin multiple ad angles for A/B testing; weekly consistent influencer content.
