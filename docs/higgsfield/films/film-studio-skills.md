## What it is

A packaging of the Hell Grind-style feature-film discipline (see [higgsfield-ai-prompt-skill.md](higgsfield-ai-prompt-skill.md)) into seven skills that an agent runs in a fixed order. The core idea: because a video model forgets everything between generations, the project's files have to do the remembering — locked references, an asset description reused word for word, written approval gates before any spend, and a strict folder structure. The skills never recommend a model; the user names their own image and video tools once and every stage reads that configuration.

## The chain (in order)

1. **setup** — one-question-at-a-time interview about which image model(s) and which video model the user works with, how each is accessed (app, CLI, or an API key held in an environment variable — only the variable's name is recorded, never the secret), the usual clip length (within a 10–15 s range) and the output folder. Writes an identical "AI film studio" section into both `CLAUDE.md` and `AGENTS.md`, then prints the chain and four ground rules: lock assets before film generation; one approved passport per asset; edit prompts one line at a time; version and log everything.
2. **studio-init** — asks only for the project name and scaffolds folders for assets (characters, locations, props), prompts, raw generations, approved selects, edit, colour, sound, master and docs. Seeds four docs: a scene breakdown table, a visual bible (asset boards, style boards, ban list), an asset registry (tag, type, version, seed file, scenes, status) and a generation log (shot, prompt version, what changed, result, verdict). Three house laws: the editor sees only the selects folder; only the prompt engineer touches raw generations; reference files are never renamed — a new version is a new file.
3. **film-breakdown** — turns a script, treatment or one-paragraph idea into a scene table and one shot-card file per scene. Every shot card has 22 fields in three lanes: identity (9 — ID, location, time of day, tagged characters/state variants, props, description, exact dialogue, running time, complexity), direction (6 — goal, task as a verb, dramaturgy, blocking, acting, style device) and camera/edit (7 — size, movement, lens, angle, cut type, pace, transition). Rules: one action per clip, target 10–15 s, split anything bigger; any on-screen text (signs, screens, titles) is pulled out into a separate text-task list because video models render text poorly — titles belong to the edit.
4. **reference-board** — builds the visual bible from references the user supplies (it does not fetch or generate images). Two axes: per-asset boards (target roughly 10–20 images for a lead character, 8–15 for a key location, 3–5 for a prop) and per-style boards (light, colour, optics, camera movement, texture, cutting tempo, sound). Every image needs a caption stating exactly what is taken from it; "just like it" images are rejected. Anti-references go into a ban list with the forbidden property named. Each board closes with a written decision — approved, revise or rejected; only approved boards count as locked.
5. **asset-passport** — one asset at a time: `@tag`, type, version, scenes, seed files. Interviews until the descriptor has no gaps (face, hair, build, skin, wardrobe, wear, marks for characters; form, scale, material, finish, markings for props; layout, surfaces, landmarks plus dominant/secondary/accent colours, light character and built-in grade for locations). Writes a single complete prose descriptor (never a short form) and a reference-sheet prompt on a neutral grey background in five views (front, three-quarter, profile, back, close). State variants are separate assets with their own tags (e.g. a character, the same character wet, the same character bloodied). Registry row starts as `draft`.
6. **stress-test** — tries to break a draft asset with cheap still images before it is allowed into video: a matrix of angles × shot sizes × the real lighting of the scenes the asset appears in × a two-shot with every co-star. Characters must pass 10 of 10; locations/props need an explicit pass decision. Only then does the registry flip to `locked`. A scene may not be generated until every asset in it is locked.
7. **shot-prompt** — refuses to write a generation-ready prompt while any in-frame asset is still draft. Writes 15 blocks in a fixed order: scene context opening with an exact character count and "no duplicates"; active references with descriptors pasted verbatim; location map in metres with the line the camera must not cross; first-frame blocking with everyone already in place; format mode; optics (one lens per shot, FOV changes only on a hard cut); the camera as a physical body (position, height, support, path, stop); action timing in 0.3–0.8 s beats; persistent physics (damage stays, debris stays where it lands); lighting from the location passport; audio with exact quoted dialogue; per-character acting including living eyes; style prefix with a 60:30:10 colour line; a quality bar; and positive constraints (every prohibition rewritten as what is present, plus a concrete failure clause). No negative-prompt section. Iteration: one changed line per version, every attempt logged; after roughly 10–15 failed attempts, simplify the shot (split it, drop an action, change the angle) instead of polishing words. Take acceptance checklist: identity and location match references, no artifacts on hands/teeth/objects or stray text, camera follows the card, performance and lip-sync hold, eyeline/axis/size/light cut with neighbours, palette matches. Accepted takes get final names in the selects folder.

## How it maps to Higgsfield work

- It is the same method Higgsfield published for Hell Grind (assets as text + image, verbatim descriptors, per-scene spatial map, character-count header, positive constraints, one-line iteration, 10–15 attempt cap) turned into gated tooling. On Higgsfield the "image model" would typically be Soul Cinema / Nano Banana / GPT Image and the "video model" Seedance 2.0/2.5 (see [cli-and-api.md](cli-and-api.md)).
- Distinctive additions versus the other repos: the formal **stress-test gate (10/10 for characters)**, the **22-field shot card** that maps one-to-one onto prompt blocks, the **captioned reference board with a ban list**, and the **selects-only rule** for the editor.
