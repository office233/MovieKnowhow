Sources:

/image and /image/soul serve the same "AI Image Generator built for professionals" page (canonical /ai-image); /create/video serves the AI Video Generator page (canonical /ai-video). Hubs are already summarised in [../../features/tools/ai-video-and-image-hubs.md](../../features/tools/ai-video-and-image-hubs.md); Cinema Studio in [../../features/tools/cinema-studio.md](../../features/tools/cinema-studio.md). /cinema-studio and /generate return the **Cinema Studio 4.0** app shell (title "Direct Every Detail": 30+ camera-movement presets, 50+ colour palettes, edit each scene independently, extend scenes).

New details on these versions of the pages:
- Image generator default shown: **Nano Banana Pro, 3:4**. Selling points: text rendering, one-click image -> video (Sora 2, Kling, Seedance), Soul ID identity lock, models in one place (Nano Banana Pro, GPT Image, Seedream, FLUX, Kling O1), native 2K refined to 4K, brush-based **Nano Banana Pro Inpaint** edits without regenerating.
- Video generator default shown: **Seedance 2.0, 8 s, Auto** aspect, audio On. Controls: first + last image reference, edit any uploaded video (styles, object swaps), motion control from a reference video, all major models (Veo, Sora, Kling, Wan...).
- Model line-up blurbs: Kling 3.0 (photorealism, motion complexity), Seedance 2.0 (native audio-video with lip-sync, SFX, music in one pass), Wan 2.7 (speed/richness balance; high-action scenes), Kling O1 (reasoning for multi-layer scene composition), Sora 2 (world simulation, physics, object permanence), Veo 3.1 (4K cinematic flows, native audio), Kling 2.6 (fast, stable character animation).
- Cinema Studio block: build a camera that doesn't exist (e.g. **16mm grit + anamorphic glass**), script-to-scene from one prompt, image reference for direction, toggle **Photography mode / Videography mode** to iterate from a still, and **stack up to 3 simultaneous camera movements**. Example camera settings shown: Camera "Modular 8K Digital", Lens "Classic Anamorphic", focal length 35mm.
