# Meet Z-Image: What's New from Alibaba in AI Image Generation?

Source: https://higgsfield.ai/blog/Z-Image-New-from-Alibaba-in-AI-Image-Generation  
Mariam Barova, Dec 1, 2025  
Prompts extracted: 2

**Z-Image** (Alibaba, open-source text-to-image): very fast (**1–3 s** per image on Higgsfield), minimal model-side filtering (Higgsfield platform safety rules still apply), responsive to prompts.
Good for: rapid character concepts/personas for storyboards, stylized art (anime, cyberpunk, fantasy, ink, cel shading, flat color), packaging/poster/merch drafts (Nano Banana Pro still better for typography), environment/worldbuilding seeds, unusual compositions.
Workflow on Higgsfield: Create Image -> Z-Image -> concise but descriptive prompt -> optional refs (face, outfit, objects, moodboard) -> format (square concept art, portrait characters, landscape environments) -> generate & iterate -> send output to Popcorn (storyboards), video models (Sora 2, Kling, Minimax, WAN), Face Swap/Soul ID, Enhancer, Instadump.
Pattern: fast drafts -> refine with other tools -> animate -> repeat.
