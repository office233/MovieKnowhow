## Practical takeaways
- Draft cheap, finish expensive: Seedance 2.5 Draft Mode (480p -> 1080p same seed), Gemini Omni Flash draft at 360p, Kling 3.0 Turbo -> Kling 3.0.
- Long single takes: Cinema Studio 4.0 / Seedance 2.5 / Wan 3.0 up to 30 s; use Extend forward/backward to continue clips.
- Fix instead of regenerate: Seedance 2.5 region edits, Cinema Studio 4.0 Edit Video, Genjutsu Object Swap, Relight and Color Palette on finished video.
- Ad variants at scale: Ad Multiplier (swap talent/wardrobe/location while keeping edit and audio).
