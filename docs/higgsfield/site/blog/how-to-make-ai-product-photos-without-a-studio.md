## Notes

**Topic:** building a full product photo set in Marketing Studio without a studio (Aug 23 2026). No prompts (template-driven).

**Template categories -> placement:** Product shot (9 formats; website, landing, product cards), Motion (animated banners/product videos up to 15 s), UGC (person with product; IG feed), Ads (Meta/Google spec banners; A/B volume), Posters (stylised brand content), Marketplace (listing covers). 1,500+ templates.
**Mechanic — Recreate:** open any template -> put your product in "Replace product" -> optional edit description -> the template's layout, lighting and style regenerate around your item.

**Steps:**
1. Clean base photo: uncluttered background, even light, product fills most of frame, readable packaging text (phone OK; clean backgrounds with Remove Background in Higgsfield Layers).
2. Add the product once in the **Product slot** (more angles + packaging refs = better consistency; name + short description) — every generation reuses it.
3. Optional avatar (people formats Closeup, Full body, Editorial, UGC): library (40 avatars), Create avatar from photos you have rights to, or a Soul 2.0 generated person; Soul ID for cross-workflow reuse.
4. Core set from Product shot formats (Closeup, Faceless, Full body, Editorial, UGC, Studio white, Color pop, Natural, Usage). Example set: **Studio white** hero; **Closeup** with avatar for detail; **Usage + Faceless** for context; **Full body** for brand mood. Add scene reference images to place the product in a specific setting. Check shape, colours, packaging text against the real item.
5. Marketplace covers: white-background hero first, lifestyle/detail next (verify marketplace rules yourself, e.g., Amazon).
6. Motion: same saved product -> animated banner.

**Costs:** product shot image 2-4 cr ($0.10-0.20); poster/marketplace banner 8 cr ($0.40); Motion banner 30-31 cr (~$1.50). Set of 8-10 images ≈ $1.60-2.40; +1 motion banner ≈ $4 total.
