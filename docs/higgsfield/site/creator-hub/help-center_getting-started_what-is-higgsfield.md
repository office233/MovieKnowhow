# What is Higgsfield?

Source: https://higgsfield.ai/creator-hub/help-center/getting-started/what-is-higgsfield
Published: Jul 29, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (overview). Higgsfield = AI-native creative suite: own tools/models + library of external models under one subscription.
- Soul (image family) + Soul ID (train a face once, reuse everywhere); Cinema Studio (camera control, multi-shot, physics-aware motion); Marketing Studio (URL/image -> UGC, unboxing, tutorial or TV-spot ads with audio and lip sync); Canvas (node pipelines, templates, collaboration); Supercomputer (agent that plans and delivers).
- External models: Seedance, Kling, Veo, Sora 2, Nano Banana and others; Higgsfield Audio (voiceover, cloning, translation).
- Suggested chain: train character (Soul ID) -> cast it in Cinema Studio scenes -> scale variations in Supercomputer. No technical skills needed for a first generation.
