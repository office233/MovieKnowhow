# What is Higgsfield MCP, and how is it different from the web?

Source: https://higgsfield.ai/creator-hub/help-center/integrations/what-is-higgsfield-mcp
Published: Aug 1, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article. Higgsfield MCP = OAuth connector (no API key) exposing Higgsfield generation to Claude and other MCP agents. Official URL only: `https://mcp.higgsfield.ai/mcp`.
- Main difference vs web: **MCP always deducts credits** at standard rates; Unlimited models and free generations only work on higgsfield.ai (also not in CLI, Canvas, Supercomputer, automations).
- Can do: image/video generation, Soul characters, Audio, balance checks. Generations land in Assets tagged MCP.
- Developer Terms apply; you are responsible for what an agent generates on your account. Not the same as the Higgsfield API (separate product, per-request USD billing).
