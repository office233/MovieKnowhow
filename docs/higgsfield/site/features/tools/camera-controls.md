# Camera Controls (motion presets hub)

Source: https://higgsfield.ai/camera-controls - "AI-crafted cinematic moves like crash zooms and crane shots, fully controllable". 67 presets. Upload a still, pick a move, generate. The underlying model varies per preset (`preset_family` in page data): 41 Higgsfield DOP (`higgsfield`, run with steps 20, 81 frames, strength 1, guide scale 6), 13 Wan 2.5, 11 MiniMax, 2 Kling.

## Using camera moves well
- Match move to intent: Dolly In / Super Dolly In (intimacy, reveal), Crash Zoom In/Out (comedy/shock), Dolly Zoom (vertigo), Arc/360 Orbit/Lazy Susan (product hero), Crane/Jib/Aerial Pullback (establishing, ending), FPV Drone / Hyperlapse (energy), Snorricam / Head Tracking / Object POV (subjective), Bullet Time (action freeze), Through Object In/Out (portal-style transitions), Car Grip / Car Chasing / Buckle Up / Road Rush (vehicle shots), Timelapse Glam/Human/Landscape.
- In Cinema Studio the same moves are `#tags` you can stack in order.
- For text prompts, the Academy camera prompt bank shows how to describe a move precisely with numbers and explicit negatives - see [academy-camera-prompt-bank.md](academy-camera-prompt-bank.md).
