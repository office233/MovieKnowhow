# How do I use Soul Cinema?

Source: https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-cinema
Published: Aug 1, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (model guide). Soul Cinema = Higgsfield's cinematic image model (deep texture, atmosphere, non-"AI" look). Image -> Soul Cinema.
- No presets or Moodboards (look is built in). Supports Soul HEX (Color Transfer) and Soul ID.
- Steps: prompt (scene, subject, mood) -> optional Soul HEX palette -> optional Soul ID character -> aspect ratio, quality, batch size (up to 4) -> Generate.
- Attaching a reference image disables the prompt field (Soul ID and HEX still work).
- Soul 2.0 characters carry over (open Character panel; run "update" if offered).
- Best for: cinematic close-up portraits, atmospheric scenes, editorial visuals, and **starting keyframes for Kling or Seedance video**.
