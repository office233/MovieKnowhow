Image-tool comparison. Higgsfield specifics:
- **Soul 2.0** flagship image model (social/fashion-aware; 30+ presets, Moodboards, Soul HEX); lighter **Soul** model with 100+ one-click presets.
- **Soul ID** trains on **20–80 photos**, a few minutes, **25 credits**; a Soul 2.0 2K image costs **0.125 credits**. Trained character carries into supported image/video models (Kling, Seedance) **through "Elements"**; into video via Cinema Studio.
- Starter from $15/mo; API available; includes Nano Banana Pro, Seedream 5.0, GPT Image.
Consistency methods ranked: re-prompting drifts within a handful of images; per-generation reference (Midjourney Omni Reference, Ideogram Character) drifts over many; LoRA (SD, Leonardo, Krea) reliable but technical; trained identity (Soul ID) = train once, no setup.
Others: Gemini/Nano Banana 2 (precise conversational edits, SynthID+C2PA), ChatGPT Images 2.0 (rewrites prompts), Leonardo (custom models), Ideogram (text in images, Character from one ref), Firefly (commercially safe), Flux (API, $0.03/MP FLUX.2 pro, LoRA), Stable Diffusion (self-host, ControlNet), Recraft (SVG/brand kit), Krea (live canvas).
