**Veo 3.1 on Higgsfield** — key specs:
- Native 1080p (also 720p), 24 fps; durations 4, 6 or 8 s; aspect 16:9 or 9:16.
- First-frame & last-frame control; Reference-to-Video (1–3 reference images for Subject Consistency — Standard model only); Draw-to-Video (sketch -> footage); Multi Reference / multi-shot mode (one prompt -> up to 4 connected scenes with transitions).
- Dialogue with lip-sync and facial expressions (Standard).
Model choice:
- **Veo 3.1 Standard**: Text-to-Video + Multi Reference; best quality and subject consistency, complex scenes, dialogue.
- **Veo 3.1 Fast**: Text-to-Video + Start & End frame; quicker, controlled motion.
Steps: Video tab -> select Veo 3.1 -> choose Standard/Fast -> give text, image(s), or start+end frames -> Generate (8 s 1080p clip).
Use-cases: Shorts/Reels at scale, multi-shot campaign assets, start/end-frame brand shots, Draw-to-Video B-roll prototypes, talking avatar intros, indie storyboards, product showcase with consistent style.
