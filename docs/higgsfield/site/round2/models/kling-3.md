Sources:

Both URLs serve the same Kling 3.0 landing (canonical /kling-3.0), already documented in [../../features/models/kling-3.0.md](../../features/models/kling-3.0.md). The detailed user guide (same article under another slug) is [../../blog/Kling-3.0-is-on-Higgsfield-User-Guide-AI-Video-Generation.md](../../blog/Kling-3.0-is-on-Higgsfield-User-Guide-AI-Video-Generation.md). Note: /kling-o1-video no longer shows Kling O1; it redirects to Kling 3.0 content.

Facts stated on this landing (useful when planning a shot):
- Up to **15 s** per generation with custom duration; "up to **6** camera cuts" in multi-shot mode (the blog/user guide says **5 shots** in custom mode - treat 5 as the safe planning limit).
- **Omni native audio**: dialogue, SFX and ambience generated with the picture; **Voice Binding** locks a voice to a character across 5 languages (English incl. American/British/Indian accents, Chinese, Japanese, Korean, Spanish); different characters can speak different languages in one scene.
- **Element consistency**: upload an image or video of the character; face, posture, clothing and voice are locked across shots.
- Physics: cloth, hair, fluids, contact collisions, weight transfer, vehicles leaning into turns.
- 3 steps: reference image -> natural-language prompt describing scenario **and sounds** -> generate.
- Use cases listed: short-form social, product ads from one product image (camera move + lighting + voice-over), short-film previs, talking avatars from one photo + audio, music videos from a reference clip.
- Free access with limited generations; premium plans add unlimited Kling access and priority.
