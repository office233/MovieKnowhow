# What uses my credits?

Source: https://higgsfield.ai/creator-hub/help-center/credits/what-uses-my-credits
Published: Aug 3, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (credits). Check Manage Account -> Usage first. Common reasons for missing credits: subscription reset at renewal; generations via MCP/CLI/Canvas/Supercomputer/automations (always billed, tagged with source); batch size 2-4 (each output billed); a failed generation's refund missing (contact Support).
