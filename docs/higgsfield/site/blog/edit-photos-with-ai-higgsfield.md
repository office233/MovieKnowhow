## Notes

**Topic:** Higgsfield Edit image tools (Aug 17 2026). No prompts.

**New tools:**
- **Layer Decomposition** — split a flat image (product shot, poster, scene) into background, subject and other elements as separately editable layers. Settings: resolution 1K/1.5K/2K, Standard or Fast, layer count (default 5). Cost: 2K with 8 layers = 24 cr ($1.20); base separation 15 cr.
- **Edit Text** — run **Detect text** (0.5 cr) to list every text line, rewrite any line, generate; new text matches original font, colour, placement. Good for prices, headlines, translated labels. ~3.5 cr ($0.18) total. Only replaces existing text (not for adding new text).
- **Remove Background** — 1 cr ($0.05); result drops straight into the project for the next step (e.g., composite into a new scene) with no download/re-upload.

**Other Edit Image tools:** Expand & Crop (AI outpainting), Upscale (2x-16x, 1080p to 8K, several engines), Color Grading, Enhancer / AI Skin Enhancer (portrait retouch, three modes), Relight (3D-aware light repositioning), **Angles** (change camera perspective, full 360 degrees, 12 auto-views + lighting control). A general prompt bar handles custom edits outside the nine tools. Access: open an image asset -> Edit Image (or the dedicated Higgsfield Layers page).
