## Notes

**Topic:** Genjutsu launch — Motion Transfer and Object Swap (Aug 31 2026). No prompts (presets-driven).
- **Motion Transfer:** take the motion/camera/timing of a source clip and apply it to a new character or rebuilt scene. **Object Swap:** replace a specified element (product, prop, outfit, character, setting) and keep everything else as filmed. Works on real or generated footage.
- Settings: 1 source video **4-30 s**; up to **30 reference images**; prompt optional (short description or preset only); **30+ presets**; output up to 1080p.
- Use cases: style swap (anime <-> live action, keep motion/camera), wardrobe change (try several outfits on one take), ad variation per market (keep pacing/structure), repurpose a phone clip into a polished commercial, AI influencer (swap who's on screen, keep the motion).
- Steps: choose feature -> upload source -> add refs -> preset or short description -> generate, compare to source, export.
- Pricing (both features): 15 s 480p 40 cr ($2.00); 15 s 720p 104 cr ($5.20); 15 s 1080p 144 cr ($7.20). (Sep 2026)
