## Notes

**Topic:** Soul Photodump (Mariam Barova, Feb 26 2026). No prompts.
- Built on Soul ID (Soul 2.0): one click produces **15 photos** of your Soul ID character in varied settings/outfits/moods (casual selfies, candids, golden hour, urban, cozy interiors) for a carousel "photo dump".
- Presets: **Male Archive** and **Cool Girl Dump**.
- Steps: choose preset -> select or create Soul ID character -> Generate -> download, curate (all 15 or ~10), order them to tell a story.
- Tips: quality of the Soul ID drives output quality (choose the best training photos); trust the built-in variety (photo dumps shouldn't look uniform); match platform format/count. Carousels are among the best-performing formats.
