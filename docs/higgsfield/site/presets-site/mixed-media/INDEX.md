# Higgsfield site — Mixed Media presets (higgsfield.ai/mixed-media-presets)

Mixed Media is Higgsfield's **video-to-video restyle** tool. You upload a clip (up to 10 s), pick a look, and the AI masks the subject automatically (no rotoscoping) and applies the style. There is **no prompt**. You set frame rate (4-24 fps), resolution (1k/2k/4k), an optional trim, and preset colours or instruments. Each preset here is also a Mixed Media-tagged chain in Effects / Viral Hub, and that effect file lists the full options and pricing.
