## Notes

**Topic:** building a consistent AI influencer (Jun 13 2026). No prompts.

**Five consistency methods:** reference image (low effort; drifts over many generations; video drifts; no speech) · LoRA (hours + dataset; strong; local control) · face swap (instant; depends on source footage; speech separate) · trained identity layer = Soul ID (3-5 min; strong across photo, video, lipsync) · hybrid (strongest, most setup).

**Pipeline:** AI Influencer Studio (visual builder, no prompts) -> Soul ID (lock identity) -> AI Video + presets (content with directed camera moves) -> Lipsync Studio (talking/UGC) -> Supercomputer (batch volume).

**AI Influencer Studio controls:** character type (human, mammal, reptile, fish, hybrid, alien; blends like "Asian + Alien"); identity (gender, origin/blends, age preset Adult/Mature/Ageless or manual, eye colour palette); face (shape, eyes incl. count and heterochromia, nose, mouth/teeth, ears/horns); body (type, height, proportions, extra limbs); skin (material, colour, patterns, effects, vitiligo, albinism, scars with placement/healing stage, freckles density/location, birthmarks, blemishes); style (hair, accessories, render style). Optional final prompt for anything missing ("add bioluminescent patterns along the arms"). Then pick aspect ratio + resolution.

**Key lessons:**
- **Imperfection is the authenticity layer** — too-perfect faces read as AI; a specific scar, asymmetric freckles, skin texture read as "someone".
- Distinctive (even non-human) characters are recognisable in half a second of scroll -> recurring audience.
- Consistency workflow: generate a batch of portraits of the finished character -> train Soul ID (20+ photos) -> use it for all content.
- Costs: build on Starter ($15/mo, 200 cr, limited models); daily posting needs Plus ($49/mo, 1,000 cr); video clips ~6-58 cr each by model (Kling 3.0 ~6-7 cr).
- Limits: consistency doesn't write your content; platform lock-in vs local LoRA; **TikTok/Instagram require labelling realistic synthetic media — disclose from day one**.
