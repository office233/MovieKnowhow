Categories: ad generation (Higgsfield Marketing Studio, HeyGen, LTX Studio, Runway, Synthesia), editing (Descript, CapCut, Premiere Pro), repurposing (OpusClip, Pictory). Most teams need more than one category.
**Marketing Studio**: product URL -> extracted images/name/features/price -> review script -> attach Soul ID -> format -> generate (audio + lip sync same pass). **Team plan $79/mo: 1,000 pooled credits, 2–9 seats**, batch variations from the same product photo/URL with one Soul ID spokesperson. Limits: **15 s clip cap** (stitch longer ads in post); template flow runs on higgsfield.ai only (not via Supercomputer/MCP at time of writing). Starter $9/120 credits.
Automation principle: fix repeating inputs (URL read once, spokesperson trained once, shared workspace) and regenerate only what changes. TikTok/Reels ads: under 30 s works best.
Other notes: Runway Gen-4.5 250 credits per 10 s; HeyGen Avatar V 20 credits/min; OpusClip 1 credit = 1 min of source; LTX Elements for reusable characters/styles/locations.
