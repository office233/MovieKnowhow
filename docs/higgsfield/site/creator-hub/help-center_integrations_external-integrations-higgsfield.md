# What external integrations does Higgsfield support?

Source: https://higgsfield.ai/creator-hub/help-center/integrations/external-integrations-higgsfield
Published: Aug 1, 2026 (5 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article. Official plugins (all spend plan credits; Unlimited/free gens only on higgsfield.ai). Default models in plugins: Nano Banana 2 (image), Seedance 2.0 (video).
- **Figma/FigJam**: Plugins -> search "Higgsfield AI". Image gen (all models), Vector (SVG), Mockup Studio, Remove BG, Color Grading, Expand, Relight, Angles, Face Swap, animation; FigJam adds Canvas Nodes. Auto-insert option.
- **Photoshop 2024+**: .UXP from higgsfield.ai/plugins/photoshop; Window -> Extensions -> Higgsfield. Generate AI Image, Realtime AI (follows brush strokes), Mockup Studio, Layer Decompose, Angles, Shots (storyboard of framing options), Character Swap, Remove BG, Face Swap, Upscale, Skin Enhancer, AI Stylist; Cinema Studio and Marketing Studio inside.
- **Premiere Pro / After Effects 2024 (24.0)+**: installer from higgsfield.ai/plugins/premiere-pro (mac .dmg; Windows ZXP Installer). Generate Video/Image into timeline (B-roll, transitions), Reframe, Remove BG, Upscale, Draw to Edit, Edit Video by prompt.
- **DaVinci Resolve**: Video/Image generation, Edit Video, Draw to Video, Reframe, Remove BG, Upscale to 4K, Color Match (build grade/LUT from source + reference frame), Import to Media Pool/Timeline.
- **Blender 5.1+**: drag .zip in; tabs Scene Builder (editable geometry), 3D Model (mesh at 3D cursor), Character Animation (rig + keyframes), Image/Video, Camera, Asset. Blender Bridge MCP connector: bridge.higgsfield.ai/mcp.
- **Minecraft 1.21.1 + NeoForge**: /higgsfield auth; Prompt to Build, Photo Slide, Video Screen/Projector, Camera, Generation Archive.
- **Higgsfield Gaming**: game builder in Supercomputer (Fable engine) or MCP; genres Platformer, Shooter, Novella, Action, Racing, Horror; styles Pixel Art, Minimal, Cartoon, Isometric, Realistic 3D, Simple 2D; publish to Games marketplace; high credit use.
