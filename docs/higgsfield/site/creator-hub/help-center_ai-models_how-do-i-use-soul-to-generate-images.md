# How do I use Soul to generate images?

Source: https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-soul-to-generate-images
Published: Aug 1, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (model guide). Soul family = Higgsfield's fashion-aware, culture-native image models.

| Model | Best for | Features |
|---|---|---|
| Soul | quick preset-driven images | style presets, avatars |
| Soul 2.0 | full control | presets, Moodboard, Soul HEX, Soul ID, reference image |
| Soul Cinema | cinematic look | Soul HEX, Soul ID, built-in cinematic style |

- **Soul**: Image -> Soul; preset categories General, TikTok Core, Instagram Aesthetics, Beauty, Mood, Camera Photo, Graphic Art; prompt optional; can generate with an avatar.
- **Soul 2.0**: combine prompt + preset or Moodboard + Soul ID + Soul HEX. With a reference image the prompt field is disabled (reference drives direction).
- **Moodboards** (Soul 2.0 only): Curated (Y2K Studio, Digital Camera, Retro BW) or Personal. Build from 20+ images of one cohesive aesthetic, **without faces**, no blurry images, no mixed styles. The model extracts lighting, texture, contrast, color.
- **Soul HEX** (Soul 2.0 + Soul Cinema): Color Transfer -> upload an image to extract its palette, or built-ins Film colors, Lime Jam, Candy pink, Nostalgic blue, Soft palette, Black gloss.
- Settings: aspect 9:16, 3:4, 2:3, 1:1, 4:3, 16:9, 3:2; quality 1.5k or 2k; batch 1-4 (each output billed).
- Some plans include one-time free Soul generation pools (web only).
