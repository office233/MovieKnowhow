# How do I use DoP?

Source: https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-dop
Published: Aug 2, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (model guide). **Higgsfield DoP** ("Director of Photography") = Higgsfield's proprietary image-to-video model, preset driven; shows as "Higgsfield Standard" in the model selector.

**Steps**: Video -> Create Video -> choose a DoP preset.
1. Keyframe image: PNG/JPG, paste, or "generate it" inline (Soul for the cinematic look, Nano Banana Pro for precision). Sharp, well-composed input is critical: DoP builds the whole shot from it.
2. Pick a preset (motion blueprint). Categories: Effects (VFX transformations), Basic Camera Control, Epic Camera Control (more intense moves), Catch the Pulse (curated themes), New, Trending; "Top Choice" = curated highlights; **Mix** combines presets in one generation.
3. Prompt with scene details; Enhance toggle auto-expands it.
4. Advanced: duration 3 or 5 s, seed, steps.
5. Cost shown on Generate button.

**Use for**: directed shots from keyframes, storytelling sequences, ads/promos, stills-first pipelines (e.g. animating Popcorn storyboards).
**Fixes**: soft/blurry -> better keyframe; wrong motion -> different preset/category; scene ignores details -> more specific prompt or Enhance. No text-only mode. DoP preset catalog is available through MCP. API prices DoP per generation.
