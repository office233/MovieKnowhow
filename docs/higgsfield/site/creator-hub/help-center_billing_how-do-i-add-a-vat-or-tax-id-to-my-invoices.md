# How do I add a VAT or tax ID to my invoices?

Source: https://higgsfield.ai/creator-hub/help-center/billing/how-do-i-add-a-vat-or-tax-id-to-my-invoices
Published: Aug 1, 2026 (2 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (billing). VAT/Tax ID only on Team, Scale, Enterprise: Manage Account -> Subscription -> Billing information -> Manage (Stripe portal). Valid VAT ID typically removes tax (reverse charge). Applies to future invoices only; reissue of past invoices via Support. Individual plans: tax auto-applied by billing location (B2C).
