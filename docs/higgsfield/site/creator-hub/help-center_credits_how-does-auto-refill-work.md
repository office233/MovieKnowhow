# How Does Auto-Refill Work?

Source: https://higgsfield.ai/creator-hub/help-center/credits/how-does-auto-refill-work
Published: Aug 3, 2026 (3 min read)
Section: creator-hub (Higgsfield Creator Hub)

Type: help article (credits). Auto-Refill: off by default; Manage Account -> Subscription -> Credits auto-refill -> Set-up & Enable. Amounts $20/$40/$90/$150/$300; rate **$1 = 18 credits**; triggers under the plan's threshold; needs saved card; not on entry-level plans. Credits valid 90 days, survive cancellation. Failed charge = no credits added. Refundable within 7 days if unused.
