## Lesson 3 — Scene 1 — The Bedroom

URL: https://higgsfield.ai/academy/courses/ai-animated-short/scene-1-the-bedroom

- First lock the hero's look (needed in all 8 scenes).
- **Keyframe in Soul Cinema**: simple prompt ("cartoon, highly stylized, man waking up in the bedroom"). A batch of 4 costs **half a credit** -> run several batches. Keeper: paper-cutout collage look, warm morning light.
- Tip: turn on **Soul Cinema's enhancer** with a very plain prompt and let it "run wild" - it proposes styles you would never ask for.
- Near-miss image? Don't reroll - fix only what's wrong in **Nano Banana Pro**.
- **Prop sheet for the watch** (appears in every scene): upload the keyframe to Claude, ask for a prop-sheet prompt in the *same style*; render in Nano Banana Pro. Sheet includes multiple angles, material breakdown, internals - so Seedance knows the watch from all sides.
- Then give Claude both images + a plain beat list (wakes, panics, message from Anna, dresses, checks watch, two routes + mystery "ultra fast" option, taps, teleports). Claude writes a shot-by-shot Seedance prompt. A few extra minutes on the prompt takes the result from decent to great.
- **Every scene = one Seedance generation under 15 s**, one style, multiple cuts/angles inside. The cap is an editing shortcut: short generations are easy to cut together, and Seedance 2.0 can hold a full scene's camera work in that window.

## Lesson 4 — Scene 2 — The Cowboy Chase

URL: https://higgsfield.ai/academy/courses/ai-animated-short/scene-2-the-cowboy-chase

- New world, same hero; the jump must feel intentional.
- Keyframe prompt barely changes shape: swap "cartoon style" -> "2D French graphic novel style" (Moebius-like), bedroom -> "futuristic environment", add a cowboy chasing him on horseback. A loaded prompt like this is worth a couple of rerolls.
- Continuity move: give Claude the **new keyframe + the Seedance prompt it wrote for Scene 1**, so it carries style, character and the teleport effect forward.
- Beat description: drops onto a horse, cowboy chases, bullet grazes him, watch press, teleport. 15 s cap, ends on teleport.
- **Three inputs into Seedance**: Claude's prompt, the new keyframe (style ref), and **the previous scene's actual video** (not a text description). The video input is what carries portal effect, character and style between worlds.
- "Consistency isn't a toggle - it's the previous shot's prompt and video handed forward every time."

## Lesson 5 — Scene 3 — The Low-Poly Arena

URL: https://higgsfield.ai/academy/courses/ai-animated-short/scene-3-the-low-poly-arena

- Setting: chibi low-poly colosseum with knights; the hero is chibi too.
- Keyframe prompt deliberately tiny (character type + setting, no camera/light) - sometimes the short version is right.
- Arena perfect, but the central figure doesn't match the hero -> **Nano Banana Pro targeted edit** (hair, black suit and tie, remove weapon, leave knights/light/arena untouched). Division of labour: Soul Cinema sets style, Nano Banana Pro fixes the character.
- Seedance prompt is an **Extend** of the previous video, continuing from the white flash of its last frame.
- Comedy detail: blocky chibi hands can't grab a weapon; he misses the watch button three times before catching it with the edge of a finger. Specific gags beat generic reaction shots.

## Lesson 8 — Scene 6 — Clay Hell
