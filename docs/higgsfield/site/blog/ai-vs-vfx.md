# AI vs VFX: Can Seedance 2.5 Beat VFX? (How To Make Realistic VFX Shots With Seedance 2.5)

Source: https://higgsfield.ai/blog/ai-vs-vfx  
Higgsfield (2026) — challenge with VFX artist Erik; host Adil; Iceland cave/waterfall dragon ride  
Prompts extracted: 16

Two parts: (1) recreate a real Iceland plate frame-for-frame with **Seedance 2.5 video-to-video** (host in cave, jump, dragon flies through waterfall); (2) a fully generated "$50,000" cinematic. Workflow motto: **Claude writes the prompts, Higgsfield makes the content** (download the free `prompt-builder-2-5.skill`, which breaks down camera, lighting and movement).
**Assets**
- Character sheet from one photo against a wall: ask Claude for a sheet prompt, generate with **Nano Banana 2 (best at matching faces)**. **Always generate character sheets on a plain grey background** (saves credits). Save as an Element, e.g. `@adil-hiking`.
- Creature: **Seedream 5.0 is best for fantasy creatures**; generate **two head close-ups — mouth open and mouth closed** to stop the face glitching between expressions.
- **Size-ref frame**: a single image of rider mounted on the dragon (combine dragon sheet + character sheet + a good previous screenshot) saved as its own asset (`@size_ref`) and attached to every scene to lock scale (e.g. dragon ~12–15x rider).
- **Face-lock trick**: crop the head out of full-body frames so the model has exactly one place to take the face from (the close-up).
- Spot slop in GPT Image 2 output (warped logo, blue-ish shift); for small fixes switch to Nano Banana 2 with a one-line edit.
- Locations: **Soul Cinema** — most cinematic; GPT skews yellow, Nano Banana too clean/symmetrical; 7 credits = 1 GPT image or **56 Soul Cinema variations** — batch and pick by light (bad light = slop in video).
**V2V rules**: cut the source into clips; **Seedance needs ≥ 4 s of video input** — freeze-frame the last shot if shorter; set duration to match the reference (longer = the model guesses). V2V handles keying/despill/light match that a compositor would do.
**When all 4 batches fail, the problem is the prompt or source, not luck** — stop batching. The jump failed in V2V because the source had no jump; fix = **image-to-video from a location screenshot as start frame**, with a written **1.5 s empty-frame pause as the cut point**, stitch in edit.
**Emotion without a reference video**: describe the face and body beat by beat — swallow, twitching fingers, clenched jaw, shaken-out hands, exhale, false start, sprint. **Seedance locks the voice with the character sheet**, so screams stay consistent.
High-speed shots: put camera language in the prompt (180° orbit, speed shake, **lens droplets**); always specify physical motion; let AI improvise background detail if it doesn't break the story.
Prompt formats used: sectioned (SCENE CONTEXT / ACTIVE REFERENCES / LOCATION MAP / FIRST FRAME AND SPATIAL BLOCKING / FORMAT MODE / OPTICS / CAMERA / ACTION TIMING / PHYSICS / LIGHTING / AUDIO / STYLE / POSITIVE LOCKS) and a reusable **global style header** (Style 8K IMAX; natural light contre-jour; Color 60:30:10; physical cine lens 180° shutter; pore-level skin; "Hollywood" acting — micro-pauses, living eyes; physics; rule of thirds; continuity; 24fps; environmental SFX only) followed by Characters / Scene / CUT blocks.
Cost/time comparison: traditional creature animation takes weeks; 3D software up to $3,000/yr.
