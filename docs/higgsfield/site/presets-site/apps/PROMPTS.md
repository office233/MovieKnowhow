# Apps: prompts

**Verbatim prompts in this section: 0.** Higgsfield Apps are prompt-free one-click presets (upload media, optionally pick an option or preset, click Generate), and no app page exposes a prompt string in its HTML or page data. The only free-text inputs are the ASMR Promo script and the AI Meme Generator character prompt and captions, and the pages give no examples for either.

Below, grouped by use-case, is **what to upload** for each app group, as a stand-in for prompts.
