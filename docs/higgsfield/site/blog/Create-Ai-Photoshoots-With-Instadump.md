# Create Realistic AI Photoshoots with Instadump

**Instadump** = prompt-free, reference-based social photo generator: one portrait -> series of natural "Instagram" photos in new environments/lighting while keeping face, pose and realism. No training; a single photo suffices.
Steps:
1. Upload a clear, well-lit, realistic portrait (not anime/stylized).
2. Choose **Presets** (20+: Meme styles, For Women, For Men, editorial/cinematic/travel/seasonal) or upload **your own reference images** to define lighting, background, tone.
3. Aspect ratio auto-matches input composition.
4. Generate — lighting/tone/shadows auto-aligned.
Best practices: high-res real portraits; match subject type between input and reference (woman->woman, man->man); frontal or 3/4 angle with neutral light; avoid heavily stylized inputs; pick references with good light, clear backgrounds.
Use: influencer feeds, campaign assets in many aesthetics, moodboards before real shoots.
